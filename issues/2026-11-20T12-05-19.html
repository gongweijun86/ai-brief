02｜CSPD用软提示组合RL专家能力

来源（X） · @alacheng · 2026-11-20 19:52

字节研究员公开了一个新的持续后训练的路径

CSPD（Composable Soft-Prompt Distillation，可组合软提示蒸馏）

把每个 RL 专家的能力蒸馏成一个独立的软提示（soft prompt），在输入空间里做“拼接合并”，而不是去改模型权重。

新的输入空间类似这样：
[软提示向量1] [软提示向量2] ... [软提示向量256] + [正常的用户输入向量]

软提示不是普通文字 token，而是一串可训练的连续向量，直接放在模型输入嵌入空间里。这里用的是 256 个 token 的软提示（参数量大约只有全模型的 0.01%）

之前是怎么把专家模型融合进去的？
1）基础模型 → 做数学RL → 得到“数学专家”
2）基础模型 → 做代码RL → 得到“代码专家”
之后想同时拥有数学+代码能力，就得把这两个专家的权重“融合”成一个模型或者用多教师蒸馏（MOPD）再训一遍。每来一个新专家，都要重新蒸馏，既麻烦，又容易把原来的能力冲掉。

CSPD如何做的？
冻结 pre-RL 的基础模型（还没做蒸馏的基础模型版本）。
用某个领域的 RL 专家（比如数学专家、代码专家）生成高质量回答。训练方式和普通 SFT 几乎一样：拿专家生成的高质量回答当目标，让“基础模型 + 这 256 个向量”去拟合专家的输出，用交叉熵损失反向传播。因为模型权重冻住了，梯度只会更新这 256 个向量只训练这个 256-token 的软提示，让冻结的基础模型 + 软提示 ≈ 专家模型的行为。

结果是：一个很小的软提示就能恢复专家 90% 以上甚至超过 100% 的增益

我们认为我们找到了一条更好的持续后训练路径：在输入空间中合并模型。

🔹 256 个 token 的 soft prompt（约 0.01% 的参数）就能匹敌全参数 RL
🔹 即插即用的组合方式：分别训练的 prompt 可以直接叠加，无需联合训练，组合效果超过各个专家。不再需要 MOPD！
🔹 更好的 OOD 泛化能力，几乎不遗忘

04｜Linger开源个人AI Agent

来源（X） · @0xLogicrw · 2026-11-20 15:31

前 DeepSeek-VL 项目负责人、DeepSeek LLM V1 研发成员张博（Tony Zhang），正式公布创业项目 Linger。

Linger 是一款运行在个人电脑上的开源 AI Agent，支持 Windows、macOS 和 Linux。它可以操作已经登录的浏览器和应用，读取邮件、日历及会议记录，并将这些信息整理成长期记忆。它还能主动提醒重要事项，根据用户反馈调整提醒规则，并调用多个 Agent 协同完成任务。

Linger 也支持本地大模型。借助 PolyStrata 推理引擎，配备 12GB 显存和 64GB 内存的电脑，就能以每秒 45.5 个 Token 的速度运行 125B 参数模型。
