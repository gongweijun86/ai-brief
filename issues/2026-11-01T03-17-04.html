06｜AlterSend点对点加密传大文件

来源（X） · @ruyi3699 · 2026-11-01 09:37

几个 GB 的文件非得先传网盘、再让对方登录去下，这么折腾不嫌绕吗？AlterSend 选的是点对点传输，文件直接在设备间走，默认不碰云端存储。

设备发现靠 Hyperswarm DHT，连上之后全程端到端加密，用的是 ChaCha20-Poly1305，临时数据在设备断开后会自动清理。

万一碰上 NAT 没法直连，它也会自动切到中继模式，但过去的仍然是加密数据流，文件内容不落地保存。

电脑、手机都吃得开，配对一次之后传文件不用反复扫码，选中设备直接发。

经常互传大文件、又懒得折腾网盘的话，这场景挺对路。

https://github.com/denislupookov/altersend

07｜CORAL自主清上下文省7倍Token

来源（X） · @snwiki238337 · 2026-10-31 13:11

一篇关于 agent 上下文的出色论文，来自CUHK、腾讯与HKUST的联合团队被 COLM 2026 接收的 Don't Lose the Thread: Empowering Long-Horizon LLM Agents with Cognitive Resource Self-Allocation。

他们把上下文清理的动作权交还给 ai 而不是依靠工程架构限制。不仅大幅拉高了复杂长任务的上限，还把推理 Token 消耗砍掉了将近 7 倍。
人类在解长难题时，大多数情况下并非记住了整个问题的所有细节，我们通常是记当下的内容，长期内容写草稿思考。
CORAL 顺着这个逻辑，将目前的 agent 上下文按照这个逻辑来做。
它们为Agent 提供了调用 MM 工具，维护一个持久化的核心面板，专门记录事实和进展两个因素。
当 Agent 感觉上下文过长或充满干扰噪音时，它会主动发起 CO 进行重置。彻底杜绝注意力分散。

为了让小模型也能自主掌握何时重置上下文，团队设计了一个多回合的算法。

它将终局获得的成败奖励穿透回合边界反向广播，并进行跨回合估计，让模型在没有额外人工标注的情况下，自主演化出最高效的记忆检查点策略。
在输实测中，在 Qwen3-8B 模型上，CORAL 取得了 42.8% 的平均准确率。

更具含金量的是它的结构分布，在需要极长推理链的 GAIA Level 2 达到 45.7%，在最难的 Level 3 斩获 19.8%。

因为 Agent 会自主在关键节点清空无用上下文，整个执行链路中的输入 Token 消耗相比传统单长链 ReAct Agent 降了 6 到 7 倍。

在BrowseComp 挑战集中，在配备完全相同搜索工具的前提下，引入 CORAL 工具集将准确率从 22.7% 推高到了 30.7%。

在未参与训练的多跳问答 MuSiQue 上同样斩获 43.2%，全面超越 Search-o1、R1-Searcher 等同期工作。
这项研究非常漂亮地打通了认知科学与 Agent 工程实践，证明了让智能体学会自己记重点并主动清内存，是突破大模型长程上下文注意力稀释的一个可行路径。
论文地址：https://arxiv.org/abs/2610.40350
