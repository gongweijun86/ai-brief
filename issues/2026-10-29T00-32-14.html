03｜网易邮箱大师上线AI邮件助手

来源（X） · @imwsl90 · 2026-10-28 14:32

【⽹易邮箱⼤师 - Mail Agent】

AI Agent 天然适合邮件服务，以至于我都想用 Vibe Coding 实现一个 AI 驱动的邮件客户端软件。

从去年到今年，我陆陆续续用过好几款邮箱 AI 产品，比如 Gmail + Gemini或第三方客户端

但总觉得差点意思：要么功能太少，要么深度不够，要么智能不足

这周开始用 网易邮箱的Mail Agent 产品，体验非常不错，亮点功能如下：

第一优先级入口：打开网易邮箱大师，即可看到页面底部的 Mail Agent 入口，点开就能用。
DeepSeek 驱动：使用 DeepSeek V4 Flash/Pro 作为 Mail Agent 的大模型。
可自定义行为准则：在个性化设置里定义人格、风格、原则和底线，方便我们打造一个贴近自己生活习惯的 Mail Agent。

说完亮点功能，也许还有同学不知道如何使用 Mail Agent，有了 Mail Agent，我们就可以把邮箱管理完全交给 AI，彻底解放检索和管理邮件的时间。

我举两个我自己的使用场景：

场景 1：Mail Agent 查询支付扣款订阅

现在是订阅时代，经常会因为自己误操作，或小孩子乱点，订阅了一个自己从来不用的服务。没有 Mail Agent，我们很难再找出这种订阅。现在有了 Mail Agent，可以让它分析我的订阅类邮件，找出疑似乱扣费的订阅，既能减少金钱损失，也能节省我们的时间。

如下图，我通过 Mail Agent 找到了一个被遗忘的喜马拉雅儿童 VIP 订阅。

场景 2：Mail Agent 帮我求职

老卫最近在找 AI 相关的岗位，每天投递很多简历，也需要花时间检索面试邀请邮件。老卫通过 Mail Agent 做了如下优化：

使用求职助理优化当前简历，重新生成一份更具竞争力的简历。

在 Mail Agent 里上传自己的简历，建立岗位匹配画像，并设置定时任务：每天早上 10 点和下午 6 点检索邮件，重点筛选与画像匹配的面试邀请。

通过这两项优化，大大节省了我的时间。我只需要专注投简历，并看看重点面试邀请即可，非常方便。

大家感兴趣的话，可以去应用市场下载网易邮箱大师，安装完即可体验 Mail Agent。

LangChain 和 LangGraph，到底啥区别？

LangGraph 更底层，流程怎么走可以自己拆、自己拼。

再往上，才是权限分开、记忆隔离、代码进虚拟环境、定时任务自己跑。

07｜Gemini 4 Carbon主打网络安全

来源（X） · @hungryturbo · 2026-10-29 07:58

谷歌的 Gemini 4 Carbon 来了，在刚更新的 AA v5.0 上居然达到了 59 分，超越 Opus 和 GPT-6 Astra 排名第一。

来快速过下核心内容：

1、首发定价跟 Argon 相同，每百万输入 token 2 美元，每百万输出 token 10 美元，缓存输入 Token，享受输入价格 95% 的折扣（即 0.1 美元 / 百万 Tokens）。

2、Carbon 在编程、智能体、科学任务、全栈 Web 开发及多模态理解上全面升级，WebDev Arena 评分提升 89 分（达 1768 分），跃升至榜单第 4 名。

3、模型覆盖了“漏洞发现、风险验证、根因修复”的完整网络安全防御生命周期，刷新内外部多项测评 SOTA。

4、在沿用 Argon 多层安全架构（实时滥用防御、思维链监控等）的基础上，Carbon 针对复杂与高压任务进行了深度对齐优化，比如在 Terminal-Bench 4.0 测试中，成功作弊率降至 0.0%（尝试作弊率降至 0.4%），内部真实编程环境中的高危未对齐警报减少了近 80%。无根据声明（幻觉/捏造）相比 Argon 减少约一半，越权操作减少 26%，执行不足减少 29%。

5、模型采用分阶段部署，本周起会先向部分网络安全防御人员和受信任的合作伙伴开放，收集反馈并迭代护栏后，将尽快全面发布。
