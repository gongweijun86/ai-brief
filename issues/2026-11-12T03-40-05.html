01｜Claude dreaming 分层记忆

来源（X） · @ElliotChen · 2026-11-12 08:55

这篇 agent memory 值得细读，几个平时容易混在一起的东西，都分开讲了。

原始对话记录留着，方便以后回查。过程中写下的笔记，记的是当时觉得有用的东西。积累多了，可以整理成互相链接的 wiki。每次新开 session，再从里面挑一小部分提前放进上下文，其他的需要时再找。

这么分开看，就比较容易理解 dreaming 在做什么了。利用任务之间的空闲时间，回头看记录，检查笔记，纠正错误，再整理一下以后怎么找。

文章也讲了为什么不能什么都记。比如玩宝可梦，当前位置和手里多少钱，屏幕上就能看到，反复存下来很快就过时了。试过哪些方法，接下来准备怎么走，这些才需要另外记着。

还有个挺好的地方，它没有把 wiki 讲成万能的。有些问题直接搜原文就能回答，整理 wiki 没有明显收益，甚至出现过 wiki 比原始文件还大的情况。需要把几份文档放在一起理解的问题，才更能体现它的用处。

看完能明白，给 agent 留一个文件夹只是开始。里面写什么，什么时候读，哪些要重新核对，都会影响它下一次做事。文中把这些做法和实验结果放在一起讲，比单看概念清楚很多。

02｜Agent 架构分清灵活与确定边界

来源（X） · @zcswl7961 · 2026-11-12 09:07

Agent 架构选型里，一个常见误区是先问“我们要用 ReAct 还是 Plan-and-Execute”。

实际的企业任务经常不是二选一：外层用 Pipeline 或状态机把权限、审批和流程节点固定下来；遇到开放问题时，在局部用 ReAct 查询和判断；步骤变多后，再由 Planner 拆解任务；关键产出最后交给测试或规则做验证。

范式不是产品标签，而是解决不同不确定性问题的工具。关键是把模型可以灵活决定的范围，和系统必须确定执行的边界分清楚。

你们设计 Agent 时，先看业务的失败成本和流程边界，还是先挑一个框架再往里套？

terminal-mac 11 月 3 日才建仓，8 天 2586 star，上了 Trendshift 日榜。

让 agent 直接操控自己的 Mac 一直让人犯怵：它点错一下，动的就是你真实的文件和账号。terminal-mac 用 Apple Virtualization 跑一台真实的 macOS 客户机，画面直接显示在 Kitty 或 iTerm2 里，客户机有自己独立的应用、文件和账户。

agent 通过 MCP 接进来，截图、点击、拖拽、滚动、打字、按键都有，还附了一份教它「先看、再动手、再验证」的技能文件。

要说清楚的是：它现在还是早期候选版本，只支持 Apple silicon 和 macOS 14 以上，发布包是自签名、没经过 Apple 公证；默认网络能访问宿主机和局域网，不是拿来跑恶意代码的隔离沙箱。

以前是人用电脑，现在得先给 agent 也配一台。

GitHub：https://github.com/govijr/terminal-mac

04｜ArcMD 还原 Arc 空间交互

来源（X） · @GitHub_Daily · 2026-11-12 09:00

Arc 浏览器马上不再更新了，不少人还惦记着它的竖向侧边栏和彩色空间。有位开发者干脆把这套交互搬进了 Markdown 编辑器。

ArcMD 是一个开源的文档编辑器，界面用 Go 原生绘制，没有 Electron 也没有 WebView，macOS 安装包只有 4 MB 左右。

每个空间对应一个文件夹，有自己的名字、图标和主题色，在侧边栏上双指一扫就滑到下一个，收藏的文档跟着走。

GitHub：https://github.com/Ciao1019/ArcMD

编辑器支持表格、公式、代码块和双栏布局，能分屏同时打开 4 篇文档，也有双链、标签和专注模式。

文档和附件都存在本地文件夹里，带自动保存和版本历史，删掉的内容会保留 30 天。Markdown 可以导入导出，页面能导出 PDF。

macOS、Windows、Linux 都有安装包。目前是早期预览版，作者还在一点点打磨，不过这个方向我挺喜欢。

06｜KiT 扩散模型预测K线走势

来源（X） · @_zheergen · 2026-11-12 08:55

我靠！有人把股票 K 线预测做成了一个 AI 基础模型，直接让 AI 生成未来可能出现的 K 线走势！

更狠的是，这个模型用数十亿根 K 线训练，覆盖美股、A 股和加密市场，还能同时预测收益率和波动率！

开源项目 KiT，一个基于 Diffusion Transformer 的金融时间序列预测模型。

以前用 AI 预测股票，很多模型只能给出下一步价格或涨跌方向，很难看出未来一段时间可能出现的完整走势。

KiT 不一样，它直接生成多条未来 K 线路径，还能展示不同预测结果的分布范围。

核心亮点：

1️⃣ 海量训练数据：覆盖美股、A 股、Crypto，包含从 1 分钟到日线的 7 种周期。

2️⃣ 未来 K 线生成：根据历史 OHLCV 数据，预测后续价格路径，而不只是涨跌信号。

3️⃣ 多周期预测：支持 1m、5m、15m、30m、1h、2h、1d，日线最多预测未来 20 根 K 线。

4️⃣ 概率区间：生成多条预测路径，展示价格可能的波动范围和不确定性。

5️⃣ 收益与波动预测：官方测试中，收益预测平均 RankIC 达 0.0571，波动率预测达 0.6600。

6️⃣ 量化回测：提供按预测收益排名选股的回测框架，考虑 A 股涨跌停、T+1、手续费和滑点。

比较有意思的是，官方还拿 Kronos、TimesFM、Chronos 等模型做了对比，KiT 在多周期预测上展示了不错的实验结果。

目前预训练模型和 100 只股票的演示数据已经公开，推理建议使用 6GB 以上显存的 CUDA 显卡，训练代码尚未开放。

做 AI 量化、股票预测、K 线建模或 Crypto 策略研究的，这个项目真的值得收藏！

https://github.com/Luciferbobo/KiT

卧槽！有人把 TradingView 上研究股票趋势、动量和成交量的指标源码全部公开了！

连 Mike Webster 的 Power Trend、Webby RSI、52 周高点分析和盘中成交量预测都有！

开源项目 peterdmv/tradingview，一套专门研究股票趋势交易的 Pine Script 指标源码库。

以前研究强势股，往往要切换多个指标，尤其是盘中成交量，很难快速判断到底有没有真正放量。

现在源码直接公开，可以自己研究计算逻辑、修改参数和交易条件。

核心亮点：

1️⃣ 多周期均线：支持 SMA、EMA、VWMA、VWAP，以及均线云。

2️⃣ Power Trend：结合 21 EMA、50 SMA，识别趋势启动与结束。

3️⃣ Webby RSI：利用 EMA、ATR 和均线偏离度，衡量动量强弱。

4️⃣ 52 周高点：结合 ATR，分析股价距离年度高点的幅度。

5️⃣ 股票数据面板：集成市值、流通股数、ADR%、ATR 和趋势强度。

6️⃣ 成交量预测：Volume Buzz、Run Rate，估算盘中放量程度和全天成交量。

比较实用的是，研究 NVDA 这类趋势股时，可以同时观察趋势结构、距离高点的幅度，以及盘中是否真正放量。

目前仓库只有 5 个指标，策略回测和公共函数库还没有实际内容，但指标源码可以直接复制到 TradingView 的 Pine Editor 研究修改。

做 TradingView、Pine Script、美股趋势交易和动量策略研究的，这套源码值得收藏！

https://github.com/peterdmv/tradingview
