06｜古诗词 API 汇集 40 万首诗歌数据

来源（X） · @bkdgiffug · 2026-10-27 07:34

四十万首中国古诗词，居然被人整成了 API 直接打包带走？

刚在 GitHub 上挖到个开源项目 chinese-poetry-api，说白了就是把将近 40 万首古诗词捯饬成开箱即用的接口，你压根不用自己爬数据、清洗、建库，接口一调诗就到手了。

它收的货有这些：
1️⃣ 宋词、唐诗、元曲
2️⃣ 楚辞、诗经这类老经典
用起来也不费劲：
1️⃣ 想按朝代、作者还是类型来捞都行
2️⃣ 全文搜、随手抽一首、简繁来回换
技术上拿 Go 写的，REST 和 GraphQL 两套接口都备着，Docker 敲一下就跑起来。做古诗小程序、搞机器人的，直接拎去用。
🔗 https://github.com/palemoky/chinese-poetry-api
