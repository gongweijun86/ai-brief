03｜DSH 定位 Agent 时代操作系统

来源（X） · @libukai · 2026-11-08 22:37

“我们的希望是，DeepSeek Harness 可以作为 Agent 时代的操作系统。”

更好玩的是，在这个操作系统上，不必再被动适应别人做的各种 App，而是能轻松打造最适合自用的专属 App。

说实话，不论远景还是前景，DeepSeek Harness 都比 WorkBuddy 大多了。

对所有希望在工作中深度应用 AI 的人而言，是时候把更多注意力多放在前者身上了，✊

引用内容

Tianyi Cui @tianyi

很多 DeepSeek Harness 插件作者都有问过我，什么样的插件和功能官方会做成内置，如果一个功能官方会做，那第三方插件做还是否有意义。

我们的希望是，DeepSeek Harness 可以作为 Agent 时代的操作系统。

所以，也许可以用操作系统来举例。以智能手机操作系统为例，系统会内置一些通用的 App，例如闹铃与计算器，满足用户的基本需求。但做手机操作系统的厂商肯定更希望生态中能出现更多更广的 App 满足更广泛的需求，希望智能手机生态中出现更好的更适合用户的闹铃 App 与计算器 App 能够比内置功能做得更好，希望第三方开发者能够使用智能手机操作系统提供的 API 做出发明智能手机的人从来没想过的 App。

DeepSeek Harness 对于第三方插件生态的想法会是类似的。我们会为用户提供稳定的基础能力，并内置大多数人都需要的通用功能。但在“一切皆插件”的设计下，内置功能同样可以被第三方插件替换，我们希望更多的社区作品成为用户的日常选择。

06｜Meta 开源 Astryx 设计系统

来源（X） · @awe0_io · 2026-11-08 16:59

Meta 这次真把家底掏出来了。

内部打磨了整整 8 年、支撑超过 13,000 个应用的设计系统，直接开源了，名字叫 Astryx。

150 多个现成 UI 组件，按钮、表单、弹窗、深色模式、品牌主题全都有。

最有意思的是，它连 AI Agent 都考虑进去了。通过 CLI 和 MCP，AI 可以直接使用组件文档和模板，不用每次写前端都从零开始造轮子。

以前让 AI 写界面，出来什么样全看运气。现在可以让它沿着一套成熟的设计规范来搭建。

而且是 MIT 开源协议，目前还处于 Beta 阶段。

GitHub：https://github.com/meta/astryx
