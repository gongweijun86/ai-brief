01｜OpenAI弃用4o系API换luna

来源（X） · @0x99DaDa · 2026-10-14 13:05

#OpenAI 今天（2026-10-14）在官方 Deprecations 页通知开发者：GPT-4o、GPT-4o mini、GPT-4.1、GPT-4.1 mini 这几档 API，将在 2027-01-14 从 API 下线——距今大约三个月。

推荐替换写的是 gpt-6-luna；这些模型的微调版跟基座同一天关。热帖里常写成「1 月 14 日」却不标年，容易看成 2026——以官网为准，是 2027。

很多人还在用 4o／4.1 当生产默认档：聊天产品早换了，接口却能继续抠旧快照的行为指纹。今天这条通知，等于把这段「产品已换代、API 仍锁旧版」的时间差正式关掉。对靠固定提示词、固定评测集过日子的团队来说，关停日比「又出了个更强模型」更扎人——因为旧行为本身就是资产。

真正要看的，是迁移成本落在谁身上：
🔹 ChatGPT 侧 GPT-4o 等早在 2026-02-13 就从聊天产品下架，当时官方写「API 暂无变化」——隔了大半年，生产侧才排上关停日
🔹 下线清单含 gpt-4o-2024-08-06、gpt-4o-2024-11-20、gpt-4o-mini-2024-07-18，以及 GPT-4.1／4.1 mini（含 2025-04-14 快照）——点名的是具体快照，不是抽象「GPT-4」口头名
🔹 依赖 4o／4.1 行为指纹、评测基线、回归用例、微调权重的团队，迁移窗只剩约三个月；换不动就断供，不是「再观望一季」
🔹 替换名直接指向 luna，说明平台对外叙事已到 GPT-6 代；旧 4 系不再是「还能慢慢用」的默认生产档，而是进弃用表的历史快照
🔹 同页还有 2026-10-01 通知：gpt-5.3-codex／gpt-5.1／gpt-5.4-nano 等到 2027-04-01 下线——另一条更长的排期，别和今天这条 4 系混成一事；主线仍是三个月内的 4o／4.1 API 搬家

一句话：产品侧换代可以快，生产 API 关停日一旦写进弃用表，评测、微调、锁定行为的团队就要按日历搬家。后面盯三件事：luna 在真实工作负载上相对 4o／4.1 的行为漂移有多大；微调客户能不能按时迁完；以及有没有人靠专用容量把关停日往后拖。

https://developers.openai.com/api/docs/deprecations

⚡OpenAI给GPT-6.1 Sol开Ultrafast，最高快8倍，API标价贵6倍！

10月8日，OpenAIDevs 宣布：GPT-6.1 Sol 的 Ultrafast 档在 API、Codex 和 ChatGPT Work 上线，称接近 Astra 智力，速度相对 Sol Standard 最高约快 8 倍。公开整理的 API 价：Ultrafast 每百万 token 输入约 12 美元、输出约 60 美元，对应 Standard 的 2/10，正好约 6 倍。

速度单独标价：
🔹同一块模型能力，买的是更低延迟的推理；service_tier: ultrafast 是开关。
🔹官方场景点名：故障排障、在应用里导航的 Agent、要跟手的现场体验。慢了就不合格的活。
🔹用「总花费÷合格结果数」：单价乘 6，只有当「慢」会直接让结果不合格、或让重试暴增时，快档才可能更便宜。

准入与口径：
🔹API 按服务档计费；Codex 和 Work 侧还看订阅与企业开关，不是所有用户一键可开。
🔹「最高约8倍」是上限口径，不是每条请求的保证值。

降温：
🔹快不等于更准；合格率仍要单独测。
🔹与其和 Astra 比智商文案，不如在自己的任务集上记两本账：标准档总花费、快档总花费，各自除掉合格条数。
🔹不荐订阅，不预测哪家模型会赢。

一句话：快档卖的是时间，贵的也是时间；时间不进合格线，这6倍就只是加价。

02｜Context Mode压缩上下文占用

来源（X） · @Jolyne_AI · 2026-10-14 13:58

Agent 调用 MCP 工具时，原始数据会全部塞进上下文，一次 Playwright 快照就有 56KB，README 里说半小时上下文就消耗掉 40%。

Context Mode 是一个 MCP server，它用沙箱工具把原始数据隔离开上下文。README 里的例子是 315KB 压到了 5.4KB。

它还能把文件修改、git 操作、任务和报错记录到 SQLite 里，对话被压缩之后，只按需检索相关部分放回，Agent 可以继续上次的工作进度。

GitHub：https://github.com/mksglu/context-mode
