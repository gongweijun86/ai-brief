5 个星标暴增最狠的项目，专业拆解下！

1. GoogleChrome/modern-web-guidance-src

Modern Web Guidance 的源码仓：把 Web 平台最佳实践和浏览器兼容数据做成技能，直接塞进你的编程 Agent，让它别再写过时套路；一行 npx 就能安装、搜索指南、扫描旧代码。由 Chrome、Edge、Firefox 和 MDN 团队共同维护。

🔗 直达：https://github.com/GoogleChrome/modern-web-guidance-src

AI 写前端最大的毛病就是「十年前的 Stack Overflow 味」，这回浏览器厂商亲自下场补课。1,875 星一天，含金量拉满！

🟢

2. openai/codex-security

OpenAI 官方的 Codex Security 命令行和 TypeScript SDK：扫描仓库或 Git 改动、验证漏洞、生成补丁并复核修复，还能导出 SARIF/JSON/CSV，接 Linear、Jira、GitHub 和 CI。

🔗 直达：https://github.com/openai/codex-security

找漏洞、验漏洞、修漏洞一条龙，安全工程师多了个不下班的搭档。754 星一天，总星 1.3 万+，AppSec 正式进入 Agent 时代！

🟢🟢

3. tailscale/tailcat

Tailscale 官方的「不用 Tailscale 的 Tailscale」：像 netcat 一样在两台机器间开 WireGuard 端到端加密隧道，自动打洞直连，不需要账号、不需要 root，纯用户态命令行和 Go 库。

🔗 直达：https://github.com/tailscale/tailcat

一个短地址就能把两台机器连起来，穿透 NAT 像喝水一样简单。324 星一天，网络老炮狂喜！

🟢🟢🟢

4. alibaba/open-code-review

阿里内部用了两年的 AI 代码审查工具开源：读 Git diff，交给带工具调用的 Agent 去翻全文件、搜代码库，输出精确到行的结构化评审意见；README 称同模型下精确率和 F1 明显高于通用 Agent，token 只用约九分之一。

🔗 直达：https://github.com/alibaba/open-code-review

数万开发者、数百万缺陷练出来的审查官，现在人人能请。206 星一天，总星 5 万+，大厂内功直接外放！

Chrome DevTools 官方给 Agent 的接口：MCP 服务 + 命令行，让 Claude、Cursor、Copilot 等编程 Agent 直接操控、检查一个真实 Chrome，录性能 trace、看网络请求、截图、读控制台。

🔗 直达：https://github.com/ChromeDevTools/chrome-devtools-mcp

05｜RIME强化学习训练Agent写记忆

来源（X） · @omarsar0 · 2026-11-14 04:13

中文译文

强烈推荐一读。

我的笔记：

我最近开始了关于共同进化模型（co-evolved models）的独立研究。我的重点在于模型与 harness 的共同进化。

这项工作专注于为持续学习（continual learning）进行记忆写入。

为什么这很重要？

当你与一个 agent 协作时，它应该在你的任务上变得更好，但这显然不会轻易发生，而且现有的外部记忆系统往往不够用。

这与记忆系统关系不大（外面有很多优秀的记忆系统），更多与模型的判断力和感知力有关——即它知道何时应该行动。

举个例子，想象一个 AI agent 花了一周时间在同一个项目中修复 bug。我们期望它能学会项目的工作原理并避免重复犯错。给它一个保存笔记的地方可以让它将这些知识带入后续任务。但选择哪些内容写入笔记需要判断力。

这项研究探讨了如何用 RL 来训练这种判断力。

他们本质上是在训练 agent 在工作过程中发现有用的信息，并写出能帮助它在后续任务中成功的记忆。

一个训练好的 4B 参数模型达到了与 GPT-5.4 和 Claude Opus 4.7 相当的分数。

RIME 让一个模型扮演两种角色。

作为 actor，它使用现有的记忆来完成任务。作为 writer，它回顾发生的事情并更新笔记，供下一个任务使用。

训练对两种角色给予不同的奖励。

writer 在接下来几个任务中表现相对近期任务有所提升时会获得奖励。这给了它保留有助于后续信息的理由。这种比较是一种近似的训练信号，因为其他动作和记忆更新也会影响这些结果。

actor 完成任务会获得奖励，发现进入记忆的信息还会获得额外奖励。一个 AI 判官会比较新旧笔记，寻找有用的补充、修正的信念和具体的线索。

这鼓励 agent 进行足够的调查以学到可复用的东西。用不同的措辞重写同样的笔记几乎得不到奖励。

研究人员发现，这些能力需要共同发展。writer 依赖于 actor 发现的信息，而 actor 依赖于 writer 保留的知识。

我在这里的一个大疑问是效率，以及它如何整合到 harness 和工作流中。我认为这种方法可以节省大量 token 和对话轮次。

虽然这只是小规模的，但看到它已经能工作是非常棒的。这感觉是持续学习的一种更可行的方法。

前沿模型在保留知识方面越来越好，但我认为高效的持续学习仍然需要触及权重，而这正是开源权重模型将发挥巨大作用的地方。

原文

Highly recommended read.

My notes:

I have recently started independent research on co-evolved models. My focus has been on co-evolving models and harnesses.

This work focuses on memory writing specifically for continual learning.

Why is this a big deal?

As you work with an agent, it should get better at your tasks, but that obviously doesn't happen easily, and current external memory systems often aren't enough.

This has less to do with memory systems (there are many great ones out there) and more to do with the model's awareness and judgment about when to act.

To illustrate, imagine an AI agent spends a week fixing bugs in the same project. We would expect it to learn how the project works and avoid repeating mistakes. Giving it a place to save notes lets it carry that knowledge into later tasks. But choosing what belongs in those notes requires judgment.

This work looks at how to train that judgment with RL.

They essentially teach an agent to discover useful information while working and write memories that help it succeed on later tasks.

A trained 4B parameter model reached a score similar to GPT-5.4 and Claude Opus 4.7.

RIME uses one model in two roles.

As the actor, it works on a task using its existing memory. As the writer, it reviews what happened and updates the notes available for the next task.

The training rewards each role differently.

The writer receives credit when performance on the next few tasks improves relative to performance on the recent tasks. This gives it a reason to preserve information that will help later. The comparison is an approximate training signal, since other actions and memory updates also affect those results.

The actor earns a reward for completing its task and an additional reward for discoveries that reach memory. An AI judge compares the old and new notes, looking for useful additions, corrected beliefs, and concrete leads.

This encourages the agent to investigate enough to learn something reusable. Rewriting the same notes in different words earns little credit.

The researchers found that these abilities need to develop together. A writer depends on the information the actor discovers, and an actor depends on the knowledge the writer preserves.

One big question I have here is efficiency and, obviously, how it all integrates into harnesses and workflows. I think approaches like this can save a lot of tokens and turns.

While this is on a small scale, it's great to see it working already. It feels like a more feasible approach for continual learning.

Frontier models are getting better at retaining knowledge, but I think efficient continual learning will still require touching the weights, which is where open-weight models will play a huge role.
