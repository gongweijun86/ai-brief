01｜GSD与Ralph轻量AI项目管理

来源（X） · @xulijian1994 · 2026-11-15 12:51

最近在研究轻量级 AI 项目管理，推荐两个 GitHub 上已经有几万 Star 的开源项目。

我想要的其实很简单：不用 Superpowers 那么重的流程，AI 能自己拆任务、记录进度、保留项目记忆，下一次打开还能接着开发，适合长期小步迭代。

1️⃣ Get Shit Done（GSD）⭐ 64.1K

主打结构化的项目管理闭环。

- 需求讨论 → 阶段规划 → 执行 → 验收 → 下一轮迭代
- 通过 STATE.md、CONTEXT.md 等文件保存项目状态和关键决策
- 每个阶段拆成独立任务，在干净的上下文中执行，减少上下文污染
- 支持中断恢复、进度跟踪，适合长期维护的项目

需要说明的是，原仓库已经归档，迁移到了 GSD Core，新仓库目前 ⭐ 11.5K，支持 Claude Code、Codex、OpenCode 等工具。

原仓库：https://github.com/gsd-build/get-shit-done

新仓库：https://github.com/open-gsd/gsd-core

2️⃣ Ralph ⭐ 22.2K

这个更极简，核心就是一个循环脚本，加上任务文件和 Git。

- prd.json：记录任务清单和完成状态
- progress.txt：记录每轮开发经验
- Git：保存每次成功迭代的代码
- 每轮只处理一个任务，通过检查后提交，再自动进入下一轮
- 每次迭代重新启动干净的上下文，通过文件恢复进度

官方实现支持 Claude Code 和 Amp，甚至不需要复杂的多 Agent 编排。

项目地址：https://github.com/snarktank/ralph

这两个我都比较推荐。

GSD 更适合需要规划、阶段管理和验收的长期项目；Ralph 更适合任务明确、希望 AI 自动一轮轮推进的小型项目。

我尤其喜欢 Ralph 这种文件驱动的方式，项目管理本来就是为了让开发更省事，没必要把管理本身搞成另一个大型项目。

03｜AI生成代码七成审查时间未降

来源（X） · @zcswl7961 · 2026-11-15 13:25

翻了下这周的 PR，AI 生成占比过了七成，Review 时长没降。

因为要核的不再是语法，是作者有没有看懂自己提交的东西。一个数据开发同事交上来一段口径校验，本地两百条样本全绿，我问他同一段逻辑在另外七处是不是也得改，他愣了半天。

他说：“我让工具按这段重写了，没去翻别的地方。”

后来我们把那七处逐一比对，发现三处字段口径已经不一样了，其中一处连 dt 分区的取法都不同。补完加上一次全量回刷，前后两天，比工具写那段多花了十倍时间。

省下的半天，最后都花在证明有人真的读懂了那段。

06｜article2media一键多平台分发

以前一篇稿子想多平台发，得自己切成小红书卡片、再去公众号后台重新排版、再录一遍口播剪成竖屏视频，一篇内容要折腾好几轮。

现在 X 长文、网页、公众号文章、本地 Markdown，甚至抖音、YouTube、B 站视频都能当原料：视频先转成逐字稿，README 里写 6 分钟的 B 站视频 16 秒就转完；口播视频配上本地语音，再用 Whisper 把字幕逐字对齐。

最省心的是每种产出都带自动验收，长图、卡片和公众号排版会逐块读回来和原文比对，不合格直接报错，不会悄悄塞给你一份错版。

拿别人的文章和视频改编之前，记得先确认授权。

一份内容写一次，剩下的交给 agent 去分发。

09｜MatrixMedia开源多平台视频发布

来源（X） · @GitHub_Daily · 2026-11-15 12:00

做自媒体的朋友应该都有体会，一条视频剪完，抖音、快手、B 站、小红书挨个登录上传，标题简介再各填一遍，光发布就要折腾好一阵。

MatrixMedia 是一个开源的多平台视频发布工具，可以把一条视频分发到多个平台的账号上，Windows 和 macOS 都能用。

目前已经支持抖音、快手、百家号、B 站、头条、视频号、小红书、番茄视频这 8 个平台自动发布，视频填本地路径或者网络链接就行。

GitHub：https://github.com/hanliang97/MatrixMedia

除了点界面操作，也能交给 AI 来发。它提供了命令行和 MCP 两种接法，Claude Code、Codex、Cursor、OpenClaw 这类工具都能直接调用。

各平台先在界面里登录一次，命令行那边直接复用登录状态。还能查每个账号是否在线，翻本机的发布记录。

把发布这一步做成能让 Agent 调的接口，这个思路我觉得挺对。手里有几个平台要同步更新的，可以装一个试试。
