05｜Claude Code 两段审查降误拦

来源（X） · @ScarletKc · 2026-10-12 19:34

最近在做 harness，研究了一圈 auto review，就是让另一个模型替你审批 agent 的工具调用。Anthropic 统计过，用户对 93% 的权限请求都点了同意，弹多了根本没人细看。

最反直觉的是 Claude Code 故意不让审查模型看工具输出，也不看 agent 自己写的话，只给它用户的消息、CLAUDE.md 和 agent 要发起的调用。这样 agent 没法写一段理由说服它放行，网页、文件和命令输出里藏的注入文本也传不到它那里。他们也试过把这些都给它看，在越界动作的测试集上表现反而变差了。代价是它分不清一个 ID 是 agent 查出来的还是瞎编的。Codex 的 reviewer 就能看到带工具输出的对话记录。

Claude Code 的审查还分两段。第一段只输出一个 token，故意偏向拦截，被拦下的再进第二段带推理复核。两段 prompt 几乎一样，第二段基本都吃缓存。Anthropic 公布的数字是误拦从 8.5% 降到 0.4%，代价是真实越界动作的漏放从 6.6% 涨到 17%，这组只有 52 条样本。

他们自己总结，危险命令其实认得出来，失误主要出在判断用户的授权覆盖到哪。用户说一句"清理一下旧分支"，agent 顺手把远程分支批量删了，就是典型的越界。

拦下来也不会卡住。拒绝理由作为工具结果回给 agent，让它换个更安全的做法，不许绕过去。Claude Code 连续拦 3 次或累计 20 次就退回人工确认，审查请求本身失败也是直接拒绝。Codex 是连续拒绝 3 次，或者最近 50 次里拒绝了 10 次，就中断这一轮。

还有一些操作压根不过审查。Claude Code 里只读操作和工作目录里的文件编辑直接放行，反正有 git 兜底。进 auto mode 的时候还会先撤掉 Bash()、Bash(python) 这种等于随便执行的放行规则，退出时再恢复。

Hatoba 的 agent 跑在 SSH 终端上，这些就不能照抄了。服务器上没有 git，authorized_keys、sudoers、crontab 改完就生效。往终端里敲一个 y，审查模型不看屏幕根本不知道它在确认什么。

07｜多智能体锁平预算后流水线最优

来源（X） · @snwiki238337 · 2026-10-12 14:22

现在绝大多数宣称“多智能体协作大幅超越单智能体”的论文，都存在一个误区，多 agent 烧更多的 token、更多的资源这是应该的。

大家总喜欢拿一个花哨的 Multi-Agent 系统去打单 Agent 基线，然后宣布协作架构取得了巨大成功。

多 Agent 之所以跑分高，到底是因为分工协调机制真有用，还是仅仅因为多烧了 Token、多调了工具、多用了几个上下文窗口。如果给单 Agent 灌进同样多的信息、同样的工具调用和同等的 Token 预算，多 agent 所谓的架构超越还剩下多少？

这篇 Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems: An Information-Controlled Empirical Study，用近乎苛刻的条件做了一次对比：严格锁死底层模型、工具权限、提示词模板和单题 Token 预算，只对比协调架构本身的影响。

他们把多 Agent 拆解为三层架构：信息层、Agent 层、以及协调层。

在 Polymarket 真实的预测市场数据集上，所有信息与计算预算完全锁平，5 种最主流的组织架构进行了一次正面的实验：

第一个独立集成，多个 Agent 各自独立思考，互不通信，最后投票平均

第二个多轮对等辩论，互相挑刺审查

第三个主从层级制，主管派发子任务并做汇总
第四个顺序流水线，单向依次传递

第五个强行共识对齐，必须讨论到所有人达成一致。

他们通过严格的统计学分解，就是Murphy 分解评估校准度与区分度，测试结果极其讽刺。

其中最被推崇的强行共识，成绩全场垫底最差。Agent 在来回妥协中发生了严重的多样性崩塌，不仅没有消除幻觉，反而把原本的敏锐异见全部抹杀，退化成一种过度自信的平庸错误。

最简单的顺序流水线拿下了第一，而完全不许交头接耳的独立集成居第二。几个 Agent 哪怕各自独立计算，最后直接把答案简单平均，效果都显著碾压其他的方式。

架构本身带有不可逆的故障指纹。而且流水线高度依赖第一步的调研质量。而越复杂的网状通信，越容易在信息对齐中自我损耗。

arxiv：https://arxiv.org/abs/2605.03310

五个工具各干各的，地址和介绍我给你一条条对上：

1️⃣ Blackbird（9100 🌟），用户名和邮箱都能查，接了 600 多个平台，查完还能免费调 AI 生成人物画像，PDF 一键导出，新手先上手这个。

🔗 https://github.com/laramies/theHarvester

🔗 https://github.com/achillean/shodan-python

说句实在的，很多小公司的 NAS、摄像头、打印机，配置都没改过，密码还是出厂默认，Shodan 一搜就出来。你以为藏住的东西，其实比你想的少太多了。自己先跑一遍，知道暴露了啥，才是第一步。
