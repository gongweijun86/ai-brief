01｜Rsbuild 2.x 承载 ChatGPT 等超大前端工程

来源（X） · @jiahan_c · 2026-10-31 11:56

最近深入支持了一些顶流 Agentic Web 工程，也是顺利都迁移到了 Rsbuild 2.x：

- Chatgpt (Rsbuild + React Router)
- Copilot (Rsbuild+ Tanstack Start)
- 豆包 (Rsbuild + Modern.js)

一些小发现：
- 前端没全死，复杂业务仍有挑战
- 在八位数代码量的大仓里，现有工具都不够快
- 多 agent 并行开发，内存成为新瓶颈
- 普遍使用 SSR
- 从零写一个超大型工程的时间被压缩至一两年
- 构建工具需要更好的按需编译和持久化缓存支持更大的研发规模
- 未来可能有分布式编译或全新的 bundler 架构来突破上限

02｜Claude Code 配置按需启用技能与流程分离

来源（X） · @F5Adon · 2026-10-31 13:49

太屌了，这份 Claude Code 配置指南，最值得抄的是它的“上岗顺序”。

先读 README，只选规划 Agent 和主力语言规则；在小仓库里跑通，再加代码审查、安全审查。用不到的技能别塞进 .claude 文件夹，缺什么再补。

开发流程也分开：先批准方案，修 bug 先跑出失败测试，改完交给没参与编写的独立上下文审 diff。写代码和给自己打分，终于不用挤在同一个脑袋里。

ECC 提供的是一套可挑选的工作流配置。把职责和检查顺序装明白，比凑一支人数吓人的 AI 团队有用。

10/29 币安被盗事件又给全行业敲了一次警钟。被攻破的不一定是代码。所有的创始人、开发团队，甚至是运营、HR等等看似离代码很远的岗位，每个人都可能是黑客的突破口。

2024年11月，我们面试过一个前端开发人员。我们收到的是中文简历，中文名字。履历里面记录了他在Bybit, 阿里巴巴等工作经历。在面试的时候，我们发现他的口音是韩式英文，并且不会说中文。我们要求他打开摄像头，摄像头那端，他的像素模糊，画面质感像15年前的摄像头。他带着头戴式耳机，有刘海，和下面截图的这个人非常相似。

我问他会不会说中文，他说不会。我问他是哪里人，他说是日本人。然后我问他在中国和新加坡的工作经历，他含糊其辞。几轮交流下来，我们怀疑他是不是朝鲜黑客，于是结束了面试。从他的简历和背景来看，造假的概率很高。

事情过去了接近两年，今天看到这张照片恍然大悟。

也在此给所有的项目方提醒：面试一定要求开摄像头，PDF不要轻易下载。一定要让全公司的同事都有安全防范意识，不要留下弱点让黑客攻击。
