01｜Pi Durable 组装常驻 Agent

来源（X） · @verysmallwoods · 2026-11-16 00:45

结合这篇文章，整理了一套用 Pi Durable + Pi AI SDK 组装 always-on Agent 的架构。

Agent 平时等待，收到消息、Webhook 或定时事件后唤醒，推进任务、保存进度，再决定何时继续，以及是否通知用户。

各个组件可以这样组合：
- Conversation 保存讨论，Submission 接收输入，用稳定 requestId 关联重复请求。
- Harness 调度 GenerationTask 和 ToolTask，完成模型生成、工具调用与后续执行。
- Durable Storage 保存历史、检查点和结果，进程重启后重新打开存储并恢复。
- Pi AI SDK 统一接入模型服务。

应用层负责事件收件箱、长期任务、记忆、审批和通知；定时唤醒可结合持久任务实现，周期规则由应用管理。外部操作还需要幂等或结果核对。

配图分三层：全局架构、主动调度循环、可恢复执行核心。

02｜magpie 下线 Antigravity 插件

来源（X） · @magpie_router · 2026-11-16 02:19

magpie 内置的 Antigravity 和我们官方的 Antigravity 插件（opencode-antigravity-auth）都已下线（v0.1.4232 起）。

原因：它们模拟客户端直连 Google 的接口，账号容易被封。现在 magpie 不再用这种方式向 Google 发任何请求。

想继续用 Antigravity，请改装社区插件「Antigravity (local agy CLI)」：通过 ACP 驱动你本机登录好的 agy CLI，请求由官方客户端自己发出。风险更低，但不是零，别多号同时高频跑。

安装：Plugins 页搜 agy，或
magpie plugin add @magpie-community/opencode-agy-cli-auth

04｜Anthropic 开源11个知识工作插件

来源（X） · @HeLi8866 · 2026-11-16 08:32

😱炸裂，由 Anthropic 官方开源的11个Plugin，在 GitHub 上已经超35000 星了！！

用来让 Claude 能在不同的工作领域里上手干活。

这些 Plugin 覆盖了不少方向，比如：

- Sales：帮忙走销售流程、管理客户，以及跟进销售机会

- Marketing：规划营销活动、做内容，以及分析营销动作

- Legal：帮忙审文件、看合同，以及处理法律流程

- Finance：分析财务信息，并处理跟财务相关的工作

- Data Analysis：查看数据、做分析，并从里面找出有用的信息

- Product Management：做产品管理、梳理需求，以及规划后续开发

每个 Plugin 具体会给 Claude 准备好什么？

这些 Plugin 各自都带了三样东西：

1. Skills：用来完成该领域工作的操作说明和专业知识。

2. Commands：可以快速执行特定任务的现成指令。

3. Connectors：接到相关工具和服务上，好让 Claude 能进入真实的工作流程里干活。

也就是说，不用每次都从零开始跟 Claude 解释，销售、营销或数据分析该怎么做，把对应的 Plugin 交给它，它就能按这个领域的 Workflow 来工作。

关键在于：这样一来，Claude Code 就不再只是写代码的工具，而会变成做专业工作的助手。

如果你在用 Claude Code，建议看看这套合集。

https://github.com/anthropics/knowledge-work-plugins

08｜Obsidian CEO 开源笔记库模板

来源（X） · @HeLi8866 · 2026-11-16 09:51

😱我靠！Obsidian 的 CEO 把自己常用的知识库模板开源到 GitHub 了！！

想靠 Obsidian 做一套属于自己的笔记库，却不清楚该怎么归类、怎么整理笔记的人，可以先从他这套模板看起。

除了这套模板，Obsidian 官方和 CEO Steph Ango（kepano）还开源了不少配套项目，我挑出了 7 个：

1、40 Questions：年终复盘清单

kepano 列的一份提问清单，帮你回看这一年或某段时期的生活。

不清楚年终复盘该从哪下手的人，可以先挑几道题，翻着日记和平时的笔记写答案。

https://github.com/kepano/40-questions

2、Minimal：Obsidian 外观

一套干净、能自己改的 Obsidian 外观。想要界面清爽一些，在 Obsidian 里打开外观市场，搜 Minimal。

https://github.com/kepano/obsidian-minimal

3、obsidian-sample-plugin：官方的插件脚手架

若你在用 Obsidian 时，觉得现成的插件不够用，可以把这份官方样板当起点，试着给自己写个插件。

还能把这个仓库发给 Codex，让它先给你讲清楚目录结构和怎么上手开发。

https://github.com/obsidianmd/obsidian-sample-plugin

4、kepano-obsidian：个人笔记库样板

Obsidian 的 CEO 把自己正在用的 Vault 样板公开到了 GitHub。里面能看到他怎么安放笔记和材料，可以下到本地慢慢研究，再按自己的情况改。

提醒一句，这只是对外公开的样板，并不是他整份私密笔记库。

https://github.com/kepano/kepano-obsidian

5、Flexoki：写文章和写代码的配色

kepano 专为写文章和写代码做的一套颜色。若你想改 Obsidian、编辑器，或自己站点的配色，不妨对照这套来调。

https://github.com/kepano/flexoki

6、obsidian-releases：插件与外观索引

这里持续更新 Obsidian 社区里的插件列表、外观列表，以及对外公布的版本资料。

要找插件、看看社区里都有什么工具，不妨从这份清单起步。仓库里并没有 Obsidian 的源码。

https://github.com/obsidianmd/obsidian-releases

7、JSON Canvas：开放的画板格式

Obsidian 的 Canvas 能把笔记、图片和点子放进同一张画板。

JSON Canvas 是用来存放这些画板内容的开放格式。若有人想琢磨画板类工具，或想搞清画板内容是怎么保存的，可以翻翻这个仓库。

https://github.com/obsidianmd/jsoncanvas
