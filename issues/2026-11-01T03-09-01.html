05｜Pi扩展生态涌现多款实用插件

来源（X） · @GitTrend0x · 2026-10-31 15:00

Pi 扩展圈又杀疯了 🔥

QuintinShaw 的动态工作流、tmonk 的 /goal 目标模式、tintinweb 的任务看板、MasuRii 的工具渲染美化、Postman 官方的 API 插件……全网玩家把 Pi 玩成了下一代「子 Agent 军团 + 自动驾驶目标 + 项目经理 + 颜值终端 + API 工程师」:

1️⃣ QuintinShaw/pi-dynamic-workflows（https://github.com/QuintinShaw/pi-dynamic-workflows）

一句话需求变成一段 JavaScript 编排脚本：把活拆给一批隔离的子 Agent 并行跑，每个任务路由到合适的模型，结果交叉核对后合成一个答案，全库审计、大型重构、多视角 Review 专用。
“一个人的需求，一整支 Agent 军团来干”！

2️⃣ tmonk/pi-goal-x（https://github.com/tmonk/pi-goal-x）

给 Pi 加上 /goal：先和你一起敲定目标、任务计划和完成标准，然后自己持续推进、记录证据，跨会话保存进度，还能交给独立的完成审核员验收；/sisyphus 模式按步骤一步步执行迁移。
“定好目标，剩下的交给 Pi 自己跑”！

3️⃣ tintinweb/pi-tasks（https://github.com/tintinweb/pi-tasks）

把 Claude Code 风格的任务追踪搬进 Pi：7 个照 Claude Code 规格写的任务工具，编辑器上方常驻任务看板，支持 blocks / blockedBy 依赖，多个 Pi 会话共享同一份任务清单，带文件锁防冲突。
“Agent 也得有自己的 Jira”！

4️⃣ MasuRii/pi-tool-display（https://github.com/MasuRii/pi-tool-display）

OpenCode 风格的工具调用渲染：read、grep、bash、edit 默认折叠成紧凑一行，改文件时给出带语法高亮的分栏或统一 diff，流式输出时就能预览待写入的改动，三套预设一键切换。
“终端也要有颜值”！

5️⃣ postmanlabs/postman-plugin（https://github.com/postmanlabs/postman-plugin）

Postman 官方出手：一条 npx @postman/postman-plugin 同时配好 Pi、Claude Code、Codex、Cursor 等编程 Agent，让 Agent 直接设计、Mock、测试、写文档、监控 API，每一步都落成文件或 CLI 命令，进 Git 和 CI 无缝衔接。
“大厂官方都来给 Pi 做插件了”！

据 OpenAI 帮助中心：从 12 月起，Plus / Pro / Business 的用量额度会在 ChatGPT 和 Codex 共用一份。
