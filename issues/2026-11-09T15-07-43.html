02｜Claude 新增只读银行账单分析

来源（X） · @Lmin0711 · 2026-11-09 21:40

Claude 现在能看你的银行账单了，但只能看，不能动。
这才是这件事最值得聊的地方。

11 月 5 日，Anthropic 上线了 Claude Personal Finance，beta，美国先行。
能用的人：美国地区的 Claude Pro、Max、Ultra 付费用户。
免费版、Team、企业版都没有。
中国用户现在看不到这个入口，哪怕挂 VPN 也看不到。

接银行的方式是 Plaid。
你在 Plaid 的窗口里自己登录银行，挑要共享的账户，授权只读访问。
Claude 从头到尾不问你要银行密码，也看不到密码。
最多能连 16 家银行，解绑随时可以，解了 Claude 就失去那家的数据。

它能看到什么？
每家你授权的账户：银行名、账户名和类型、后四位、余额、信用额度，
以及最长 24 个月，也就是两年的交易记录，
每笔交易带金额、日期、商家、分类和银行写的备注。
贷款、信用卡、投资账户只给余额和额度，
持仓、交易、利率、贷款条款这些它看不到。

它能干什么？
用大白话回答你关于钱的问题。
这个月外卖花了多少？下个月有哪些账单要付？哪类开支涨得最快？
它可以按你的真实账单算出来，而不是让你自己贴数字。

它不能干什么？
不能转账，不能管钱，不能替你投资。
Anthropic 自己也说，这个功能不是用来给投资建议的。
余额还可能比银行 App 慢一两天，
它自己也提醒：重要数字先跟银行对一下，答案可能算错。

隐私上它划了两条线。
第一，Personal Finance hub 里的对话不用于训练。
第二，用了银行账户的对话不会产生记忆。
这在今天的 AI 产品里算克制的。
但话说回来，你把两年账单交给一个模型，
信任的其实不是技术，是它会不会守住这条线。

对独立开发者来说，这事有另一层意思。
AI 正在从“帮你写代码”往“帮你管生活”走，
下一步就是它要读你的真实数据，才给得出有用的答案。
谁先拿到你的数据入口，谁就先拿到下一轮的用户粘性。
Claude 这次选了最难的一块：钱。
只读、不动钱、不给投资建议，
这个姿态很聪明，也很克制。

问题留给你：
如果国内哪天也有类似功能，你会把银行账单接给 AI 吗？
还是说，钱这件事，你宁愿自己算？

03｜LongCat-2.5 开源1.6T多模态

来源（X） · @hungryturbo · 2026-11-09 22:30

美团的 LongCat-2.5 正式开源了，再来回顾下核心点：

1、总参数 1.6T，激活 48B，支持 1M 上下文，MIT 协议，专门针对长程智能体、完整代码库构建和复杂办公交付设计的原生多模态模型。

2、普通模型写大项目容易半路崩盘，LongCat-2.5 直接收集真实智能体的失败轨迹，转化为可复现，可验证的训练任务。开发者实测它能直接端到端搓出带后台的多场景打斗游戏和完整的 Skill 网站。

3、长程任务动辄几万步，重头算太慢了，它用 Partial Rollout 异步训练让没跑完的任务存档续跑，动态过滤掉全对或全错的无效样本，还能跨版本修正旧轨迹偏差，让模型在超长任务里稳得住。

4、模型做题经常爱偷懒（比如翻 Git 历史抄答案，死循环调工具），这次训练环境直接网断了，还清空了 Git 历史和缓存，并且使用 LLM 裁判盯住轨迹，严惩过度思考和无效调用，实测能独立交付小店互动经营网站等复杂逻辑项目。

5、它没有外挂视觉模块，而是用残差向量量化（RVQ）把画面变成和文字平权的离散 Token，视觉和代码在同一个主干网络里协同思考，实测一句话就能生成汽车发布会 3D 演示站、水族馆交互网、水墨仙侠游戏 UI。

6、办公的核心是吞下多份脏数据，算准账，产出规范的交付物。在开发者实测中，它能自动整合多渠道电商数据、厘清数据口径算出真实利润，直接端到端生成一个可交互的电商经营分析工作台。

7、国产卡显存不到 80GB，训长文本极易爆显存或卡在跨机通信上。团队用双重分片（FSDP）和词表切分把模型拆碎摊平，并将最吃带宽的数据交换死死锁在超节点内部的高速局域网里，避免跨机器堵车。

8、万亿模型落地最怕推理的成本高，团队采用 W4A4 方案（基于 FlatQuant），把模型权重和激活同时压缩到 4-bit，在数据分发前就完成瘦身，下游表现几乎不掉点，把部署和调用的成本打下来了。

05｜dsh-media-desk 自媒体全流程

来源（X） · @long_jingai · 2026-11-09 19:25

我只能说，不愧是 DeepSeek Harness 官方认可的插件：自媒体工作台（dsh-media-desk）

上手体验了一下，真的太优雅了😋

整个工作台分为五个模块：灵感、内容、排期、复盘、风格

1. 灵感
平时刷到什么有意思的视频、看到什么值得做的选题，直接通过对话丢进去，能沉淀成一张张可视化灵感卡片，哪天感觉来了，想去做了，点一下就能进入内容制作

2. 内容
内置了各种内容风格，选好风格，一键生成对应的视频脚本、配图，但是要自己配置好 API Key，不满意就直接对话修改，直到满意为止

3. 排期
内容做好之后，直接安排发布日期，在排期模块里就能看到所有内容，整个流程非常丝滑

4. 复盘
我自己做自媒体一直懒得复盘，这里内置了复盘模块，可以导入自己的内容数据进行分析，再接个大肥鱼，催着我复盘，督促我

5. 风格
虽然预设了很多风格，但真正好用的还得是你自己的风格，它支持导入自己过去的内容，让 AI 学习、提炼你的个人风格

从灵感收集、内容制作、排期发布，到最后的数据复盘，整个流程都串起来了

这是一个很好的自媒体工作台开发框架，如果要做自己的自媒体工作台，其实没必要从零开始，在这个的基础上再去二改就挺好
