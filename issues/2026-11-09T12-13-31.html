01｜GrokBot 调度 Claude Code

来源（X） · @vincemask · 2026-11-09 19:34

GrokBot × Claude Code 方案

直接利用 GrokBot 自带的云电脑，把 Claude Code 变成它的执行工具。

整个流程很简单：

1、让 GrokBot 在云电脑里安装 Claude Code CLI

2、手动完成 Claude 订阅登录在云端电脑登录

3、GrokBot 负责理解需求、拆解任务、调用 Claude Code

4、Claude Code 负责写代码、操作文件、运行测试，完成后返回结果

这样，GrokBot 负责调度，Claude Code 负责执行。手机上就能分配开发任务，不需要本地电脑一直开机。

05｜DSH 源码七包拆解 Agent 骨架

来源（X） · @uudonX · 2026-11-09 06:02

想读懂 dsh 的源码？先把这七个包背下来

给你一个偷懒的办法，读源码之前，背这张表：

session：只追加的事件日志。
system-prompt：提示词片段和工具 schema 的组装。
tools：带作用域的工具注册表加执行流水线。
agent：Agent 接口和 agent/* 事件。
agent-loop：默认的驱动器。
scope：按 agent 划分作用域的原语。
llm：消息、流式词汇和适配器接口。

背完你会发现，整个 agent 的骨架就这七块，其他全是围着它们长出来的。
