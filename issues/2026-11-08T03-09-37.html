01｜Clash开源内核单连接超10Gbps

来源（X） · @ClashbyClash · 2026-11-07 18:30

Clash 迎来一次重大性能突破：Mac、iPhone 和 iPad，单连接下载全部超过 10 Gbit/s。

现在，支撑这些成绩的内核，完整源码已经公开。你可以查看它如何工作、自己构建和复测，也可以继续改进它。

先看这次的真机实测：
Mac mini（M4 Pro）：14.16 Gbit/s
iPhone 17 Pro Max：12.29 Gbit/s
iPad Pro（M2）：11.00 Gbit/s
Apple TV 4K：8.32 Gbit/s

以上为各设备的本机回环测试，衡量流量经过隧道、规则和代理节点时的处理能力。实际上网速度取决于网络和节点。

这次，我们改到了协议栈。
Clash Core 继续基于 mihomo，但在 Apple 平台的隧道中，我们接入了 sing-tun 的 Go 协议栈，替换原有的 TUN stack 路径，并围绕 Apple 设备完成适配与优化。相关实现已经公开，改了什么、如何接入，都能直接查看。
成熟的实现，也有继续突破的空间。开源让我们能够深入底层做出改变，也让这些改变成为其他开发者可以继续使用的成果。
万兆性能背后的实现，现在免费开放。
Clash Core 的完整内核、Apple 绑定和 SDK 构建工具均已开源，遵循 GPL-3.0 许可。开发者可以对照上游检查改动，下载源码自行构建，在自己的设备上复测，或在遵守许可的前提下集成和改进。源码与构建说明
我们希望，这次突破能成为更多开发者的起点。有人验证它，有人发现问题，也有人把它推向更高的性能。
感谢 mihomo、sing-box、sing-tun 及其贡献者。社区长期积累的代码与经验，让这次改造成为可能；我们也把自己的实现继续公开，让这份积累接着向前。
万兆已经跑出来了，源码也已经放出来了。欢迎复测，欢迎继续突破。

02｜agent-desktop免截图后台操控

来源（X） · @ChappelDae55911 · 2026-11-07 23:58

刚试了下还行

引用内容

雪踏乌云 @Pluvio9yte

全体起立，Vercel推出的agent-desktop现在才是Agent操控电脑的真神。

它是 Vercel Labs 的开源项目，Apache-2.0 协议，GitHub 已经有 1.8 万 star，仓库地址在下面

它是一个命令行工具，让 Claude Code、Codex 这类 Agent 直接操作你电脑上的 App：点按钮、填表单、打字、切菜单、读界面。

之前大部分 Computer Use 的做法是截图，再让模型猜该点哪个坐标。慢，还容易点歪。

agent-desktop 不截图。它直接读系统的无障碍树（就是读屏软件用的那套接口），给界面上每个按钮、输入框编一个号，Agent 按编号去点、去输入。

最关键的一点：它默认不动你的鼠标，也不把窗口切到前台。

Agent 在后台操作电脑的时候，你可以照常刷微信、写东西，两边互不干扰。真要用物理鼠标键盘时，再加 --headed。

我在自己的 Mac 上实测了一轮：

- 打开系统设置，读完整个界面 0.3 秒左右
- 点击「蓝牙」0.17 秒，页面切过去了，设备列表也读出来了
- 给不在前台的文本编辑输入一段中英文加数字，0.15 秒，读回来一字不差
- Electron 写的 App 也能读，侧栏、对话列表的文字都拿得到
- 整个过程我一直在用微信，前台一次都没被抢

我原来用 LCU，它要借 ChatGPT 桌面端里面的运行时，ChatGPT 一更新就可能坏，也卡过。今天卸了，换成 agent-desktop。

几个让我决定换的点：

1. 不依赖任何 App，npm 一装就能用
2. macOS（Intel 和 M 芯片）、Windows、Linux 都支持
3. 自己不带模型，任何能跑命令的 Agent 都能用，也可以当 MCP 服务接进去
4. 60 个命令，窗口管理、剪贴板、通知、菜单栏都包了

安装就两步：

npm install -g agent-desktop
agent-desktop permissions --guide

第二条在 Mac 上会一步步引导你打开辅助功能权限。

然后在 AGENTS.md 或 CLAUDE.md 里加一句：

Use `agent-desktop` to see and operate desktop apps. Before the first use, run
`agent-desktop skills get desktop` and `agent-desktop skills get platform`, and follow them.

你的 Agent 就会用了。

仓库：https://github.com/vercel-labs/agent-desktop

04｜AI专家数据稀缺靠外包难突破

来源（X） · @Lynncc6 · 2026-11-07 17:14

在大厂做了差不多一年AI专家数据，接触过一些数据生产、供应商管理和模型训练相关的工作。看到这些非常有共鸣，给一些内部视角：

大量司内员工的使用数据被合成用于训练，正在以不同形式被整理、筛选和合成，再回流到训练流程中。我们称为回流。沉淀真实一线工程师在工作中遇到的问题：代码库、复杂的工程环境、实际的 Debug 过程，以及那些很难通过普通 Prompt 构造出来的长尾场景

虽然是司内数据，但并不意味着可以无条件用于训练，数据授权、隐私保护和内部合规依然是必须解决的问题。但大家都在默许这些的发生

优质数商正在从外包进化为模型研发合作伙伴。过去数商的核心能力是组织人力、执行标注规范、控制交付质量。但现在，优秀的数商已经开始具备更完整的技术和研究能力，可扩展的合成生成系统、同时懂RL数据和领域的工程师、能够判断什么任务对模型真正有用，以及自己提出任务的能力，而不是只响应甲方需求

简单同质化数据越来越不值钱，单价低至几块钱，能提供可靠学习信号的数据才有价值，而这这需要极高的领域知识 + 实验设计 + 质量控制。一个任务可能很长、很复杂、需要大量人工时间，但如果它无法区分模型能力的高低，或者无法提供稳定、有效的反馈，那么它对训练的价值仍然有限

专家人类数据仍是稀缺品，如何组织数百万人类专家高效生产高质量数据，是当下需要攻克的难点。 普通的外包专家做不出足够挑战模型的数据。尤其是在复杂编程、数学推理、科研、法律、金融等专业领域，模型需要学习的不只是标准答案，还包括专家如何拆解问题、如何做出判断、如何发现错误，以及如何在不确定条件下推进任务

这类数据的难点在于：1）真正有能力挑战前沿模型的专家数量有限。普通外包专家可以完成标准化任务，但很难稳定生产模型当前能力边界附近的高难度任务。2）专家的时间非常昂贵。让一个领域专家从头到尾完成数据生产，成本高、效率低，而且不同专家之间的产出质量存在差异。3）专家知识很难被标准化。很多专业判断依赖隐性经验，不容易转化成清晰的标注规范和评分标准。4）专家数据的质量验证本身也需要专家。这导致生产成本和质检成本很难简单地通过增加人力来解决

AI 数据岗位也在面临非常明显的岗位价值重构。Data PM 需要理解更多模型训练逻辑：模型当前缺什么能力？什么样的数据能够弥补这个能力缺口？应该如何设计任务和数据分布？什么样的质量标准才有意义？如何通过实验判断数据是否真正有效？作为交付运营，上游是数据PM，下游是标注交付管理，流程标准化、人数多、很容易被自动化和外包吃掉，被锁在执行层，价值闭环难达到

晚点 LatePost @latepostnews

大模型的数据生意：人类如何蒸馏自己

-当网上现成的文本越来越难满足训练需求，模型公司开始从人类的实际工作中收集数据。 2026 年初，中国模型公司开始行动，腾讯混元负责人姚顺雨直接管理混元数据团队；阿里将服务大模型的数据团队交给集团合伙人委员会成员范禹；字节在年中将 Seed 旗下 Global Data 团队升级为 AI 数据与安全部门，与 Seed 平行，服务所有大模型团队。

- 用户完成任务时留下的操作轨迹，成为模型训练最受重视的数据之一。一位互联网公司数据团队人士说，目前最迫切的需求是编程和工作两类。编程数据有两种用途：练习评测集中的题目，在排行榜上拿高分；或学习实际任务，比如开发游戏、搭建 3D 模型。据我们了解，需求最旺盛时，一些模型厂每天在编程数据上的投入可以超过 1000 万美元。
工作数据则要还原办公过程：从文件里找资料、读懂邮件中的要求和期限，再往表格里填数字、编辑文档、查询网页和数据库、调用工具。一位数据服务商创始人说，金融和法律行业的经济价值高，大量任务在线上完成、以 Office 文件交付，是比较理想的训练环境。

- 一条人工数据售价从几百元到上万元不等，一批通常至少 1000 条。海外报价的数字相近，单位则换成美元。一位 Seed 后训练团队人士说，员工为 AI 陪伴产品猫箱编写对话，用户说一句、模型回复一次算一轮。一条长数据有 100-200 轮，审核通过后报酬基本能上千元。参与者有编剧、文学创作者，也有审核和编辑人员。“有的人一个月就能拿上万元。”一位在 AI 数据平台兼职的法律行业人士说，她每月交付约 40 条数据，拿到 2 万多元，平均每条约 600 元。第一次做一条花了 75 分钟，熟悉后约半小时。

- 还有一些交易不在明面上。创业公司攒下一批模型厂商账号，转卖 API 调用服务，再出售调用产生的数据。另一些公司从模型公司内部人员手里买数据，转卖给同行；经手人可能在算法、工程、基础设施或采购岗位。部分交易靠回扣维系，单笔合同数百万元乃至上千万元，内部人员从中分成。“每天就像是在捡钱。” 一位数据供应商说。

- 模型公司很难全靠自己生产数据。外部供应商愿意一份数据卖多家。但大厂则普遍愿意支付 3-4 倍溢价，永久买断或限时独占。今天合格的训练数据，半年后可能只剩一成有用。等竞争对手能买到，价值已经不同了。

- 大厂高价买断数据，但买家仍得知道自己要什么。蚂蚁买金融数据时，会把一个投研报告类需求拆成上百个案例、十多个子类，写清每类多少篇、案例什么样。“做蚂蚁的项目很多时候是亏钱的。” 一位服务商说，细致的要求增加了交付难度。

- 在 DeepSeek，绝大多数员工从事数据相关工作。“梁文峰偶尔也会参与数据标记。” 一位 DeepSeek 人士说。姚顺雨接手混元后，重新清洗已有数据、迭代基础设施，让混元 3 Preview 明显超越前代；正式版再优化后训练数据、扩大强化学习规模，能力又有提升。

- 数据工作的重要性上升，但数据生产人员的收入不一定能跟着模型能力涨。一位头部互联网公司的研究员说，公司一支团队做了 1 万条数据，训练效果很好。很多参与者月薪只有 8000-9000 元，按 18 薪算，一年不到 20 万元。同一公司的算法人员，年薪包则在 1000 万元左右。效果上去了，奖励主要给算法团队；数据做得好坏，员工到手的钱差别不大。

- 最近一年，多个公司的后训练团队往往每一两个月就要发一个版本，研究员从早上 10 点半工作到深夜，休假也带着电脑。“本质上大家在技术路径、数据处理和质量上都拉不开代差，就看谁先发出来。” 一位后训练研究员说，“很多事拖个两三个月，做出来也没了意义。”

- 为了加快训练，研究员开始让模型参与数据生产和研发。他们指挥模型批量收集、修改数据，再让更强的模型检查结果。OpenAI 披露，编程 Agent 已参与研究员的日常工作，包括写实验代码、跑测试和排查基础设施故障；Anthropic 也称，Claude 曾在约 2 小时内完成一项通常需要工程师两三天的故障排查和修复工作。

- 研究员把各行业专家的知识、经验和判断做成数据，训练模型接手他们的工作。现在，模型要学的，也包括研究员每天正在做的事。

06｜Claude科研会话近半用于数据分析

来源（X） · @Xudong07452910 · 2026-11-08 09:23

推荐 Anthropic 刚发布的《How researchers use Claude》，文章中分析了 20 多万条科研相关的 Claude 会话，看看 AI 到底在帮研究人员做些什么。

其中 Claude Code 近一半的科研会话都在做数据分析，用于提出研究想法和假设的却只有 2.1%。

但在另一项科研人员调查中，大家反而把提出研究问题和假设看得最重要。

文章还尝试解释了背后的技术原因。

作者把科研工作拆成具体任务，发现 AI 的能力与任务是否适合 RL 高度相关。像写代码、统计分析，结果容易验证，也能快速获得反馈；而一个研究假设究竟有没有价值，往往很难立即判断。

另一个值得关注的变化来自 Claude Science。

它把蛋白质结构、药物、论文等专业数据库接入同一个 Workflow，让 Agent 能跨工具收集证据、分析问题。假设生成类任务在 Claude Science 中的占比也更高，不过这还不能证明提升完全来自工具接入。

所以 Research Agent 接下来值得投入的方向，是把文献检索、数据分析和实验验证真正串起来。

让 Agent 提出一个想法已经不难，如何让它找到可靠证据、设计验证方法，并根据结果不断修正，才是更有挑战性的部分。

原文：https://www.anthropic.com/research/how-researchers-use-claude
