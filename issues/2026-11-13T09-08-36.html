03｜Agent 查询租户隔离移入网关

来源（X） · @zcswl7961 · 2026-11-13 16:10

听做数据平台的负责人讲，一次查询漏了租户字段。

他们给几个客户共用一个查询服务，AI 生成的取数 SQL 本地跑两百次都顺，谁都没多想。

上线第三天做月度汇总，Agent 拼条件时漏了 tenant_id，一次把三个客户的明细扫进同一张结果表，下游日报跟着串了数。

他后来给我看监控：「平时两分钟的活，那天跑了四十分钟，还是客户先发现报表里多了别家的名字。」

权限条件只写在 Prompt 里，执行层没做强制拼接，模型一偷懒就整段漏掉。后来把租户条件挪进查询网关，另加一道结果集校验。省下的半天，赔进去一晚排查加一次客户说明。

你们让 Agent 拼查询条件，租户隔离是写在提示词里，还是压在执行层？

06｜Agent 超时重试需幂等键与状态核对

来源（X） · @zcswl7961 · 2026-11-13 15:06

给准备把 Agent 接进数据中台的团队一句实在话：先写清失败重试的边界。

我见过最险的一次，是工具调用超时之后 Agent 自己又发了一次 Schema 变更。上一轮到底成没成，它并不知道，只是按「超时就重试」继续跑。

带教的 TL 当时说了句：「模型这轮说完成了，可元数据里那张表到底建没建，谁也没查。」

问题不在模型，在写操作没幂等键，也没先查执行状态就重放。建表、改字段、发告警这类动作，重放一次就是两份真实后果，事后清元数据和修血缘的成本翻了一倍。

先把幂等键和状态核对放进去，再谈要不要换框架，这一层换了框架照样得自己写。

你们的 Agent 遇到超时但结果未知，是先重试，还是先查一次执行状态？

07｜欧拉讲题实时生成动画讲解

学生家长的救星来了
刷到个网易新推出的AI教育产品：欧拉讲题

我测试了下，果然有点牛P，能实时生成讲题动画过程啊，边讲边画动画

你还能实时互动

曾经几何题我最烦的就是：过 A 点作一条辅助线

线我会画，但怎么想到往这儿画的？😂

讲到辅助线这一步，你可以打断它，问「为什么要画成平行的？」让它接着在图上讲：哪些角因此相等，又怎么用这些角找出相似三角形。

我觉得有意思的是，它会先规划怎么讲这道题，再把讲解变成板书、图形、动画和语音的指令。说到哪个角，图上就标到哪个角；你卡在哪一步，它就从那一步接着讲。
