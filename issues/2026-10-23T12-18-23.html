02｜Claude Design Skill 移植至开源 BaoCut

来源（X） · @liangzhu_AI · 2026-10-23 14:38

宝玉大佬把 Claude Design 彻底逆向成了一个开源 Skill，这套思路太值得偷师了。

为什么 Claude 做出来的界面审美高级、排版克制，而其他模型生成的页面花里胡哨？
宝玉逆向后发现了核心底牌：Claude 底层默认挂载了一套极其严谨的 Design System Skill（设计系统规范）。
他把这套设计心法提取出来，接入到 GPT-6.1 Sol 等其他模型上，
生成界面的高级感瞬间被拉满。

更厉害的是他在开源剪辑工具 BaoCut 里的架构思路：
不仅仅做单调的视频剪辑，而是顺手把上游的幻灯片演讲、UI 界面设计全流程一网打尽。
做垂直 Agent 绝不能只盯主功能，把上下游的设计环节全吃进来，
产品壁垒直接提升一个维度。

引用内容

宝玉 @dotey

这两天逆向玩上瘾了，又逆向了最新的 Claude Design。没想到 GPT-6.1 Sol 接上 Claude Design （最新 Artifacts 里面那个版本）的 Skill 后，设计能力有很大提升，可能因为 Claude Design 会默认使用 Claude Design System Skill。

本来我做 BaoCut 只想做一个专注于视频剪辑的 Agent，结果把 Claude Slides 和 Claude Design 也给加进去了。

都说做产品经理克制很重要，但有时候好东西就忍不住加进去，知易行难，我还得继续修行。

理论上来说，可以把 Claude Design 和 Claude Slides 作为 Skill 的，但是没办法支持编辑修改和标记，所以先只是集成到 BaoCut 中。

当然 baocut 是开源的，skill 和前端代码你都看的到：
Design Skill 相关 commit：https://github.com/JimLiu/baocut/commit/7aa049e8

如果你只是想试试，可以下载 baocut 或者本地运行，使用你本机 agent cli（比如 codex），会话的时候选一下 design skill。

当然 baocut 最强大的还是视频相关的功能，比如你可以用本地模型去转录，基于转录结果去翻译字幕，生成切片等等。

https://baocut.com

🛡️ 建议：
在使用不受信任的项目之前，先审查 .vscode/settings.json 和终端启动参数。如果已确认执行或无法排除执行的可能，请隔离受影响的主机进行调查，然后从受信任的设备上转移钱包资产并轮换相关凭据。
