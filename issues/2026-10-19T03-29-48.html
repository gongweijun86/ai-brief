03｜LayerFS 沙箱隔离细化到工具调用

来源（X） · @ScarletKc · 2026-10-19 05:29

之前和 Yifan 聊 Multi-Agent Harness，听到了一个很有意思的设计。

他想让多个 Coding Agent 基于同一份项目状态协作，但不依赖 Git Worktree 来隔离每个 Agent。

他的思路是把沙箱隔离粒度缩小到每次 Tool Call。

每次工具调用都有独立的临时 Workspace，执行完可以保存为 Commit，也可以直接丢弃。底层通过 Zero-copy fork、COW 和内容去重，让不同 Agent 共享已有文件状态。

我第一反应是：你干脆重新发明 Git 吧。

但看完他的 LayerFS 设计文档，发现还真有点东西。

现在常见的 Agent 沙箱主要按 Task 隔离，而他希望做到 Tool Call 级别，让每一步操作都能独立执行、追溯、回滚和分叉。

这样不仅能支持更细粒度的多 Agent 协作，还能让 Agent 从任意保留的中间状态继续探索其他方案。

更有意思的是，他说这个想法半年前就写进 README 了。

引用内容

Yifan Xu @yifanxu_ephai

别说agent不是7x24小时执行任务，agent就算在执行任务也80%的时间都在思考。之前cloudflare出了篇blog分析token economics，就指出了这个问题。

如果只有在用到bash时候启动沙箱，像read，write，edit直接通过文件系统提供的api/sdk进行操作。agent估计对沙箱的真实需求只占任务时间的5%。

2. 他的流量来自 AI 帮忙写的 SEO 文章。他甚至自己做了一个开源的命令行工具，每天自动找出"有曝光、没点击"的关键词，写一篇文章发出去，每天只发一篇。

05｜Numa 本地DNS解析器集成去广告

来源（X） · @wlzh · 2026-10-18 07:49

发现一个挺有意思的开源项目：Numa，一个用 Rust 写的 DNS 解析器，装在自己笔记本上跑。

一个 ~8MB 的二进制文件，干的事不少：

本地开发爽了：服务不用记端口号，frontend . numa 直接在浏览器打开，自带 HTTPS 绿锁，WebSocket 热更新也透传。不用 mkcert、不用 nginx、不用改 /etc/hosts。

去广告：Hagezi Pro 规则每天更新，咖啡馆、酒店、机场，走到哪挡到哪，不用再搭树莓派。

隐私拉满：支持 ODoH（Oblivious DoH），查询加密后经中继转发——中继知道你是谁但看不到你问了啥，目标知道问了啥但不知道你是谁。

还能当递归解析器用，直接从根域名服务器查，带 DNSSEC 全链验证；手机也好接，一行命令出二维码，扫一下手机的 DNS 就切过来了。

MIT 开源，1.5k star，macOS/Linux/Windows 都能装。

https://github.com/razvandimescu/numa
