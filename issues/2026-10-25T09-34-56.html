01｜Agent入门教程可视化执行与上下文

来源（X） · @antiAIvo · 2026-10-25 13:09

用claude做了一个新栏目：Agent入门实践
https://nano-ai.tech/agent/

很多人觉得 Agent 很复杂
其实拆开看，它就是一个 while 循环：
调模型，执行工具，把结果写回上下文，再调模型
难懂的地方在于
你看不到上下文在循环里是怎么变的
这个栏目就是把它画出来，一格一格播给你看
怎么用：

左边栏选章节，一共 10 章
从一次 LLM 调用讲到一个完整的 coding agent
每章中间有一个播放器
点「播放」自动走，点「下一格」手动走

播放器左边是代码，黄色高亮的是当前执行到的那一行
右边是此刻的上下文
每种角色一个颜色：system、user、assistant、工具结果
刚加进来的那一块会亮黄
外框变成黄色，表示这一刻整个上下文正在发给模型

播放器下面是 token 计量条，每调用一次模型就多一条。
浅色是重发的历史，深色是这一圈新加的
看完你就明白，为什么 Agent 跑久了又贵又慢

10 章分别是：
一次调用、工具调用、Agent Loop、上下文窗口
规划、记忆、MCP 与 Skills、子 Agent、失败模式、实战拆解
建议先看第 3 章 Agent Loop
看懂这十几行代码，后面每一章都是在它上面加东西

所有人都说在 iPhone 上实现"Hey Grok"是不可能的。连 Grok 自己都说 Apple 把唤醒词功能只留给 Siri。所以我继续深挖，最终找到了一个方法。现在我只需要说"Hey Grok"，Grok Bot 语音聊天就会自动打开。不需要额外的应用，不收费，全部内置于 iOS 中。

如何设置：

1. 确保你的 Grok Bot 应用是最新的

2. 快捷指令 App → + → 添加操作 → 搜索"Grok Bot" → 选择"Start Voice Chat with Bot"

3. 设置 → 辅助功能 → 语音快捷指令 → 设置 → 选择那个快捷指令 → 输入"Hey Grok"并说出3遍

4. 在快捷指令的详细信息中，开启"Allow Running When Locked"（允许在锁定时运行）

如果你的手机是锁屏状态，iOS 会先要求你点一下。如果 Face ID 已经解锁了手机，那就可以完全免提操作。

原文

Everyone said "Hey Grok" was impossible on iPhone. Even Grok said Apple keeps wake words for Siri only. So I kept digging, and I found a way. Now I just say "Hey Grok" and Grok Bot voice chat opens. No extra apps, no cost, all built into iOS.

How to set it up:

1. Make sure your Grok Bot app is up to date

2. Shortcuts app → + → Add Action → search "Grok Bot" → pick "Start Voice Chat with Bot"

3. Settings → Accessibility → Vocal Shortcuts → Set Up → pick that shortcut → type "Hey Grok" and say it 3 times

4. In the shortcut's details, turn on "Allow Running When Locked"

If your phone is locked, iOS asks for one tap first. If Face ID already unlocked it, it's fully hands-free.
