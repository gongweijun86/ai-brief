01｜HF 推出 Agent 后训练教程

来源（X） · @Xudong07452910 · 2026-10-31 09:10

想自己训练一个真正会用工具的 Agent，却不知道从哪开始？Hugging Face 最近整理的这套教程，我觉得很多人正好需要。

名字叫《A curriculum for post-training agents》，用 Coding Agent 贯穿整个学习过程。

从 SFT 学习工具调用轨迹，到模型蒸馏、GRPO，再到 OpenEnv 多轮交互，最后教你如何在真实 Harness 中训练 Agent。

其中有一个实验很有意思。作者故意设计了容易被钻空子的奖励函数，结果训练分数越来越高，实际代码测试表现却越来越差，把 Reward Hacking 这个坑讲得很直观。

每个阶段都配了视频、讲义、TRL 文档，部分还有训练代码和实际案例，可以顺着一步步学下来。

对于已经会搭 Agent，想进一步理解 Agent RL、训练环境和 Harness 的人，这套学习路线很值得收藏。

https://huggingface.co/blog/huggingface/train-agents

04｜MotionSites 做电影感落地页

来源（X） · @Ryrenz · 2026-10-31 11:05

🎬 让 Claude 做出电影感网页的外挂来了：MotionSites Web Builder，一个免费的 Claude 技能。

MotionSites Web Builder 仓库 10 月 26 号才建，四天就 1100 多个 star。

平时让 AI 写落地页，常见结果是能跑但很土：配色随便、动效生硬、手机上一看还溢出，你只能一轮轮截图回去让它改。

这个技能把这套活提前做了：Claude 先参考 MotionSites 上最受欢迎的设计，从 50 多个主视觉视频、30 个透明 3D 抠图和 29 张图片里挑素材，写好设计规格再动手。液态玻璃、无缝视频循环、滚动叙事、Three.js 3D 模型这类效果，有 55 个以上带代码的配方可以直接套。

最关键的是写完它会自己截图检查：资源坏没坏、手机端溢不溢出、字体和视频对不对，按评分标准修完再交给你。配合 Playwright 效果最好。

http://Claude.ai、桌面版和 Claude Code 都能装。注意技能的指令和代码是 MIT，示例提示词和媒体素材版权归 MotionSites。

AI 做网页，终于学会先看再改了。

GitHub：https://github.com/Motionsites-AI/claude-skill
