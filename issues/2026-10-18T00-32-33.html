05｜OpenGCUA 写代码替代 GUI 点击

来源（X） · @CMGS1988 · 2026-10-17 17:06

阿里的这个论文就是我最近卷的 side proj 方向，5 级判断择优调用，o55 med osworld v2.1 直接干到了 90+，成本和时间都只有目前世界第一的 1/20，哦对了这个世界第一幕后黑手也是…但他们怎么可以发论文啊！！！妈的！！！！

引用内容

Context Window @ContextWindow_

中文译文

让一个计算机使用智能体编写 Python 而不仅仅是点击操作，所有八个前沿模型的表现都有所提升。在 OSWorld-v2 上的平均部分得分从 45.3 提升到 64.9，每个任务的步骤减少了 53%。

OpenGCUA 背后的阿里巴巴团队让模型将每一步写成一个混合了 GUI 操作和 shell 命令的程序。该程序可以检查结果并选择下一步操作，而无需再次调用模型。模型还自行决定何时需要截图，并维护自己的待办清单，这两项工作过去由运行框架按固定规则完成。

– GPT-6 Astra：67.1 提升至 75.7，每任务步骤从 102.1 降至 33.5
– GLM-5.3-Flash：29.6 提升至 64.9
– 编写代码 vs. 纯 GUI 加 shell 访问：+6.1 分，步骤减少 14.8%

所有八个模型的运行框架、提示词和轨迹均已开源。

注意事项：这是 OSWorld-v2 的 82 个任务的离线测试集。真实设备的运行框架和跨设备 SDK 处于早期阶段，仅在四个 macOS 任务上进行了测试。

https://arxiv.org/abs/2610.22200

原文

Let a computer-use agent write Python instead of only clicking, and all eight frontier models tested get better. Mean partial score on OSWorld-v2 goes from 45.3 to 64.9, with 53% fewer steps per task.

The Alibaba team behind OpenGCUA has the model write each step as one program that mixes GUI actions and shell commands. The program can check a result and pick the next move without another model call. The model also decides when it needs a screenshot and keeps its own todo list, two jobs the harness used to do by fixed rule.

– GPT-6 Astra: 67.1 to 75.7, steps per task 102.1 to 33.5
– GLM-5.3-Flash: 29.6 to 64.9
– Code vs. plain GUI plus shell access: +6.1 points, 14.8% fewer steps

The harness, prompts and trajectories from all eight models are released.

Caveat: this is the 82-task offline set of OSWorld-v2. The real-device harness and cross-device SDK are early, tested on only four macOS tasks.

https://arxiv.org/abs/2610.22200
