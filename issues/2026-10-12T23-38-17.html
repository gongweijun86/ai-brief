01｜hd-lang 用规则审计驱动AI开发

来源（X） · @hd_nvim · 2026-10-12 12:18

那也来说一下我是怎么做自动 24 小时自动提交的
https://github.com/HerringtonDarkholme/hd-lang
1. 首先软件领域很重要，我做的是程序语言编译器，输入输出固定，规则明确，非常适合给 AI 定义目标和指标，容易做出爬坡
2. 人类主要负责 Spec 的大方向（Spec 本身也是 vibe 的）
3. Spec 用了一条一条的规则，可以用rule-id来脚本枚举审计
4. 每条 rule-id搭配了 Conformance test case，机械可验证
5. 实现上用了TS 做 pilot 实现，先做个玩具试水，把指标刷上去，看看会有什么坑
6. TS 实现完了 作为参考再重新设计架构，AI 分步做大框架/组件进行设计
7. 人类给出大体评价，然后得知道重点组件需要多来几遍AI设计/审核
8. 时常抽查代码，完全不看代码AI 会走捷径乱实现
9. 使用不同模型，Opus做主研发， ChatGPT Sol6.1审计专门找边缘情况（在语言设计的时候很有用）
10. 最主要的还是领域容易做，容易验证。所以在其他领域设计新系统的时候得先进行验证的设计

最后，我心态开放，可以随便质疑，甚至可以转帖骂我，我无所谓

02｜ego lite驱动Agent端到端测试

来源（X） · @huangtongxueh · 2026-10-13 00:49

跟大家分享一下我构建Agent端到端测试的一套方案：
pi + DeepSeek Flash + ego lite
主要用来完成日常开发的自动化测试

简单来说：
1. ego lite：负责实际操作浏览器，包括页面交互、状态读取和结果验证，开源，可以丝滑导入你的chrome配置
2. pi：作为 Agent Harness，负责整个任务的执行和工具调度，开源，你完全可以基于你的业务测试需求二开
3.DeepSeek v4.1 Flash：tps很高的模型，调用成本很低，提高自动化测试的效率

比较方便的是，不需要提前写一整套 Playwright 脚本，直接用自然语言描述测试流程，就可以让 Agent 自动完成页面操作、检查结果。固定的一些sop可以直接沉淀为skill

我拿实际开发过程中的三类 Web UI 任务做了一轮小规模测试，包括信息查询、多轮交互、状态修改及持久化验证对比了几套不同的 Agent + Model + Browser 组合，附了张脱敏后的测试对比图，大家可以参考一下。

ego lite这个产品的构建理念我还蛮喜欢的：
1. 共享登录的浏览器状态
2.agent友好的设计
3.并行多任务处理的优化

而且它给了蛮多的最佳实践，比如：
1. 抓取并聚合社交媒体帖子
2. 自动查找并申请职位
3. 自动投递简历
如果你有一些idea，完全可以把它嵌入到你的工作流
搭配上pi + deepseek flash，实现速度+成本上的提升

最重要的是还开源，完全可以基于自己的需求做一些定制化开发。美中不足的是只支持mac，windows系统的小伙伴可以再等等。

原文

China has killed the entire vector database industry.

They open-sourced TencentDB Agent Memory. It gives any AI agent long-term memory that runs 100% locally.

No Pinecone. No cloud APIs. No repeating yourself every session.

- 61% fewer tokens
- PersonaMem accuracy: 48% → 76%
- Zero external API dependencies
- Runs on plain SQLite

Most memory systems compress your history into an opaque vector pile. when recall goes wrong, you're guessing. this one doesn't compress, it builds a semantic pyramid.

L0 Conversation → L1 Atom → L2 Scenario → L3 Persona.
