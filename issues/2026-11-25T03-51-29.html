07｜Claude通过MCP分发Skills

来源（X） · @shao__meng · 2026-11-25 10:58

Claude 官方升级 MCP：按需分发 Skills、后台执行 Tasks，让工具连接变成完整任务委派

连接上工具，不代表 Agent 就知道怎样把工作做好。Claude 官方更新的重点，是让 MCP 服务器同时提供操作能力、使用经验和更完整的执行流程。
https://claude.com/resources/articles/skills-over-mcp-tasks-and-more

# Skills over MCP：通过 MCP 分发 Skills

这里的 over 是“通过”，不是“胜过”。服务器除了提供工具和资源，还能发布包含 SKILL.md 与辅助文件的 Skills，告诉 Claude 如何组合工具、遵循业务规则、完成多步骤任务。

Skills 按需加载，并随服务器更新，用户不必再单独安装一份操作指南；内容还可以按账户或组织定制。

例如，Shopify 提供整套网店设计与更新流程，HubSpot 引导客户完成配置，Atlassian 结合组织上下文分析工作。Carta 根据文档协助起草和发行股权的能力则仍待推出。

但 Skills 内容不等于用户授权。客户端仍需将服务器提供的内容视为不可信输入，不能因为操作指南要求某个动作，就自动授予执行权限。

# Tasks：把长任务交给服务器

这里的 Tasks 是 MCP 的异步执行扩展，不是待办清单或定时提醒。

服务器先返回任务 ID，再在后台执行耗时操作，甚至完整的 Agent 循环。Claude 可以继续处理其他工作，随后查询状态、获取结果；断线重连后，也能凭 ID 继续查询。ZoomInfo 用它完成更深入的企业与联系人研究，将原先需要多轮提示的流程一次委派。

这不保证任务无限期运行。客户端与服务器都要支持扩展，保留期限由服务器决定；取消也是协作请求，不保证服务器立即停工。

# 执行中可以提问，也能传文件

Elicitation 允许服务器通过表单或链接向用户补充提问、请求确认，再继续执行。例如，Supabase 在创建付费项目或执行破坏性 SQL 前确认，GitHub 要求用户输入仓库名后才允许删除。

密码、API 密钥等敏感信息不能通过普通表单收集，应走外部链接流程。

File Uploads 让 PDF、表格、图片直接传给服务器，传输过程不必经过模型上下文窗口。但这不代表模型阅读文件也不消耗上下文。关联开发文档仍将其标为测试功能与实验扩展，并有连接器和存储域名等要求。

# 哪些已经可用？

按公告内容，Claude 和 Claude Code 中：
· Skills over MCP 为公开测试，Pro、Max、Ultra 默认开启；Team 需管理员启用，Enterprise 尚待推出。
· Tasks 与 Elicitation 已正式可用，覆盖上述个人付费套餐，正向 Team、Enterprise 推送。
· File Uploads 即将逐步推出，具体取决于套餐、服务器支持与组织设置。

此外，官方称工具搜索可在多服务器配置中，将工具定义占用的上下文减少超过 85%。这里减少的是工具定义的开销，不能理解为总 token 成本降低 85%。
