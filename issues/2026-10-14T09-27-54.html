02｜Anthropic 2021路线图曝光

来源（X） · @AI_Whisper_X · 2026-10-14 17:02

卧槽，Anthropic 2021年就在讨论这些了吗？

这是 Anthropic 2021 年 7 月的研究路线图，在 Bartz 版权案里被当作证据公开了，读完有点震撼。
- 顶层目标就是 AGI，落到具体是做一个能对话的 AI 助手，写函数、找 bug、设计 API、聊代码风格，“具备一个软件工程师同事的全部能力”
- 训练 1T 及以上的模型，用自动奖励 + 人类反馈做 RL 微调，那时 GPT-3 也才 175B
- 硬件 de-risk：TPU、Trainium，为 compute deals 做准备；最值钱的资产是模型权重，要加强安全
- 数据：language、code、diffs、PRs、debugging，拿 diffs 和 PRs 去 finetune，"把人的意图和模型行为连起来"
- long context 和 memory，批注里还提了三种 memory 方案：periodic batched backprop、soft database lookup、skeletonization
- reward model 的鲁棒性，对齐的 scaling law
- 单独一节 RL for Tool Use，先在 search 和 printf debugging 上看到 signs of life
- 批注区 Dario 有一句："Yep. Basically the code editor."

每一个词现在看都不吃惊。但 2021 年 7 月，GPT-3 还是天花板，Copilot 预览版刚出两周，这些东西全部同时出现在一份文档里。人的认知差距，真的可以跨这么多年。

其他同时公开的还有

《Product visions for early 2025》（2025 年初产品愿景）：写于 2023 年 6 月，讨论 Claude 未来可能的用途。https://storage.courtlistener.com/recap/gov.uscourts.cand.434709/gov.uscourts.cand.434709.563.4.pdf

05｜Claude团队用记忆循环替代提示词

来源（X） · @huxlab · 2026-10-14 12:18

Anthropic 的工程师说：我们内部已经不怎么写 prompt 了，写的是循环。

她在台上花了半小时，展示了 Claude 团队如何创建能够自我提示的循环。

如果这堂课卖 700 刀，今年 Agent 课的榜单大概就是它。但它是免费的。

真正拉开代际差距的，不是谁的 Prompt 写得好，而是Agent系统架构彻底换了：

1. 记忆从一份 CLAUDE.md，进化成 Agent 自己读写的 memory/ 目录

2. 记忆待在对话里会烂掉：注意力被劈开，规律被埋住，旧笔记还在自信地用错

3. 白天各 Agent 把进展写进团队记忆

4. 夜里再跑一轮 dreaming：核对、整理、补全。第二天开工的那个，自动比昨天聪明一点

数据结果也很直观：一次通过的错误少了 97%，验收快了 30%。人回去看产品，不再一直盯着提示词。

提示词是一次性的，而循环能够持续执行。

差的不是你会不会问。

是你的 Agent 睡一觉之后，还记不记得昨天学到的东西。

06｜REA接Claude Code做自动逆向

来源（X） · @tspy · 2026-10-13 15:05

迄今为止，逆向工具 REA 最佳使用宝典

我把逆向分析和开发做成了一套全自动工作台：Grok Bot + REA + Claude Code + DeepSeek + Cursor CLI

分工如下：

· Grok Bot 当总指挥，在云电脑上帮我装工具、配环境、派活、验收、汇报

· REA 是开源的逆向工具，负责拆 App、读代码、抓页面，它本身不调用大模型

· Claude Code 是调用 REA 做分析的 agent，通过 MCP 把 REA 的 139 个工具接进来

· DeepSeek 是 Claude Code 背后的模型，走它兼容 Anthropic 的接口，平时用便宜的 deepseek-flash，难的换 v4-pro

· Cursor CLI 专门负责开发，照着逆向分析的结果写代码

配置只有三步：

1. 把 Claude Code 的接口地址指向 http://api.deepseek.com/anthropic，key 从本机文件读取

2. 运行 rea setup --client claude_code，把 REA 注册进 Claude Code

3. 开发项目都交给 Cursor CLI （授权登录）

你只需要跟 grok bot 对话，要逆向什么软件、要复刻什么工具即可。

所有过程都在云电脑桌面的终端里跑，随时能看着。

适合想复刻、研究开源软件的人。可以直接 @ bot 让它照这个方案部署！

友情提示：不要用 claude 和 gpt 模型做逆向分析！！！
