03｜Cordis插件树用原型链实现继承

来源（X） · @antiAIvo · 2026-11-09 20:49

学习 DeepSeek Harness 之 TypeScript 原型链

为了搞懂 DSH 底下的插件框架 Cordis
学 TypeScript 时发现一个很有意思的点
准确说是 JavaScript 的特性：对象可以直接继承另一个对象

举个例子：
const b = Object.create(a) // b 以 a 为原型
const c = Object.create(b) // c 以 b 为原型
c.x // 读 c 的属性 x

c 自己没有 x，就去 b 找，b 没有，再去 a 找
这个往上找的过程，是引擎自动完成的

这和 Java 那种类继承不一样
类继承继承的是模板，拿不到某个对象运行时里装的数据
原型继承继承的是一个活着的对象
a 现在有什么、以后再加什么，c 都能读到
Go、Java、C++ 都没有这个语法
想要同样效果，只能把父对象当参数传进去
存成 parent 字段，再手写一层层往上找

这就是 Cordis 插件树的地基：
每个插件拿到一个 Object.create 出来的子 ctx
能读到上层所有东西，自己写的只留在自己这一层
