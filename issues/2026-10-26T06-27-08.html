01｜Hassan 六步闭环应用开发工作流

来源（X） · @shao__meng · 2026-10-26 12:09

Hassan 把他日常做应用的工作流公开了！

语音 → 视觉参考 → 澄清问答 → v1 反馈 → 录屏验收 → 发帖或扔掉 的闭环；harness 混用 Claude Code（Opus 5.5 high） 与 OpenCode（DeepSeek V4.1 Flash / GLM 5.3），并给 Agent 接上部署/模型/设计类 CLI 与 skills。

六步工作流
· 用 @WisprFlow 录 1–5 分钟语音作 prompt，细节越多越好
· 补视觉灵感：截图，或 Inspo MCP，让 Agent 知道想要的样子
· 用 @mattpocockuk 的 grill-me skill，让 Agent 主动追问澄清，而不是一上来闷头写
· 拿到 v1 后，再发一串反馈、功能需求与设计微调（通常又是一段语音）
· 每个新功能合并 PR 前，先要一段 快速录屏，证明真能跑
· 迭代到满意再发到 X；不满意就扔掉

工具栈
· Harness：Claude Code + Opus 5.5（high）；OpenCode + DeepSeek V4.1 Flash / GLM 5.3
· 给 Agent 的能力：Vercel + GitHub CLI（推代码、部署）；Together skills（聊天/图像/语音模型）；Design/animation skills（间距与交互指引）

Hassan @nutlope

中文译文

我如今构建应用的方式：

1. 用 @WisprFlow 录制一段1到5分钟的提示词。细节越多越好。
2. 添加视觉灵感，让 agent 知道我脑中的想法（截图或 Inspo MCP）。
3. 使用 @mattpocockuk 的 grill-me 技能，让 agent 提出澄清性问题。
4. 拿到一个 v1，然后发送一份反馈列表、功能请求和设计调整（通常也是通过另一段语音录制）。
5. 对每个新功能，要求进行一次快速屏幕录制，在合并 PR 之前验证它是否正常工作。
6. 不断迭代直到我满意为止，然后发布到 @X 上或者直接扔掉。

我的工具组合使用 Claude Code 搭配 Opus 5.5 (high) 以及 OpenCode 搭配 DeepSeek V4.1 Flash / GLM 5.3。

我还给我的 agent 提供了一些 CLI 和技能：

• Vercel + GitHub CLI，这样它们就可以推送代码和部署应用。
• Together 技能，这样它们就可以使用 Together 的聊天、图像和语音模型。
• 设计/动画技能，这样它们就有了关于间距和交互的指导。

原文

How I build apps these days:

1. Record a 1-5 minute prompt with @WisprFlow The more detail, the better.
2. Add visual inspo so the agent knows what I have in mind (screenshots or Inspo MCP).
3. Use @mattpocockuk's grill-me skill to have the agent ask clarifying questions.
4. Get back a v1, then send a list of feedback, feature requests, and design tweaks (via another voice recording usually).
5. For each new feature, ask for a quick screen recording to verify it works before merging the PR.
6. Keep iterating until I'm happy, then post it on @X or throw it away.

For my harness, I use a mix of Claude Code with Opus 5.5 (high) and OpenCode with DeepSeek V4.1 Flash / GLM 5.3.

I also give my agents some CLIs & skills:

• Vercel + GitHub CLIs so they can push code and deploy apps.
• Together skills so they can use chat, image, & voice models from Together
• Design/animation skills so they have guidance on spacing & interactions

07｜Pi Agent 接Ollama断网编码

来源（X） · @HunziDaily · 2026-10-26 13:20

如果你在体制内、涉及商业秘密，或者单纯不想花一分钱 API 费？
Pi Agent + 本地 Ollama 是目前开发界公认最强、最轻巧的【全离线安全孤岛】！

极简配置只需要两步：
1. 本地启动 Ollama，跑一个开源模型（如 deepseek-r1:8b 或 qwen2.5-coder:7b）；
2. 在终端启动 Pi 时直接指定本地端点：
`pi --provider ollama --model qwen2.5-coder:7b`

这时候你直接把网线拔掉、断开 Wi-Fi 试试看！
Pi 依然在你的终端里健步如飞地帮你读代码、写文件、改 Bug！
所有的计算全压榨在你自己电脑的显卡上，没有任何一个字节飞出你的房间，
极致的隐私安全感，商业大厂给再多钱都买不到！
