02｜diagram-design统一图表风格

来源（X） · @AISuperDomain · 2026-10-13 08:12

把旧架构图交给 Agent，重画成统一品牌风格的文章配图。

diagram-design 是一个开源绘图 Skill，支持 Claude Code、Codex、Cursor 等工具，适合写技术文章、做演示时统一图表的配色、字体和布局。

它把设计规范写进了 Skill：4px 网格、1px 细线、无阴影，用一个强调色突出重点。

覆盖 45 种图型，包括架构图、流程图、时序图、甘特图等。
提供网站 URL，可提取品牌配色和字体，应用到后续图表。
支持重画 Mermaid、http://draw.io、Excalidraw 源文件，并列出合并、省略了哪些内容。
生成单个 HTML 文件，内嵌 SVG，浏览器即可打开；也可导出 SVG / PNG，PNG 导出需安装 Playwright 和 Chromium。

效果取决于所用模型，同一提示词的布局也可能不同。修改要继续让 Agent 调整或编辑 SVG，没有可拖拽的画布。需要随代码频繁修改、审查差异的图，Mermaid 仍更合适。

安装：
npx skills add cathrynlavery/diagram-design

https://github.com/cathrynlavery/diagram-design

03｜BitNet 用CPU跑千亿参数模型

来源（X） · @Ryrenz · 2026-10-13 08:01

🔋 太省了，微软开源的 BitNet 能让一颗普通 CPU 跑起 1000 亿参数的大模型，不用显卡。

BitNet 在 GitHub 狂揽 4 万 stars，仓库 2024 年 8 月才建，三千七百多个 fork 说明真有人拿它在干活。

平时想在自己机器上跑个稍微大点的模型，第一道坎永远是显存：装不进去，就只能换更小的，或者去租卡。BitNet 的做法是把权重压到 1.58 bit 这个极限档位，让 CPU 直接吃下去——官方测下来，x86 上比传统方案快 2.37 到 6.17 倍、能耗降 71.9% 到 82.2%，ARM 上快 1.37 到 5.07 倍、能耗降 55.4% 到 70%。那个 1000 亿参数的模型在单颗 CPU 上大概每秒出 5 到 7 个词。

微软自己也顺着这条路放了一串 1-bit 模型，包括 24 亿参数的 BitNet-b1.58-2B-4T 和两个嵌入模型，还有一个在 CPU 上跑实时多语言语音识别的 VibeASR.cpp。

显卡价格这么离谱的时候，省电省卡本身就是功能。

GitHub：https://github.com/microsoft/BitNet

04｜ARTEX 开源AI渗透测试平台

来源（X） · @kafkaup · 2026-10-13 06:50

百度"agent+"攻防挑战赛的冠军项目开源了，Go 写的后端配 Next.js 前端，今天一天涨了 113 star。它叫 ARTEX，做的是 AI 自主渗透测试。我按它的 README 把一次使用走了一遍。

① 装。clone 下来跑 http://install.sh，脚本会先检测并装 Docker，然后让你选全部 Docker 还是本地编译。选本地的话它会生成 config.json，用 go build 加 embedui tag 编译成一个内嵌前端的单二进制。依赖只有 PostgreSQL。装完开 8787 端口，首次进 setup 设管理员密码。

② 配。LLM 支持 ANTHROPIC_API_KEY 或 OPENAI_API_KEY，环境变量和 UI 里都能填，也能指定 base_url 和代理。远程 MCP 可以接 Streamable HTTP 或旧版 SSE。每个任务的 work agent 数在系统设置里改，默认 3。

③ 喂资产。如果你本来在用 ScopeSentry，填地址和 API Key 就能按项目或任务维度把域名、子域、IP、端口、站点、端点同步过来，直接进 ARTEX 的资产图供 agent 探索。Docker 镜像里已经带了 nmap、playwright、ripgrep 这些。

④ 跑起来之后，界面上能看到会话与工具调用的完整执行过程、力导向布局的资产覆盖图（已测节点高亮、可折叠展开）、流量录制、发现列表，以及 Token 消耗统计。关键动作走拦截审批，你在对话里点同意才继续，这是人在环路的部分。

工程细节挺用心：页面一键更新会比对 Release 的 SHA256、用 -h 冒烟测试新二进制，连续 3 次启动失败自动回滚到 artex.old。

两个要注意的地方：版本还在 0.3.3，更新即重启会打断正在跑的任务；Docker 下的一键更新只换程序不换镜像，nmap、playwright 那套工具链得自己 docker compose pull。另外这类工具的使用边界你自己清楚，别拿去打没授权的目标。

05｜StudentSim 模拟学生改进教学

来源（X） · @AISuperDomain · 2026-10-13 07:44

微软开源 StudentSim：给 AI 老师配上“会犯错的学生”。

做 AI 家教，光看模型能不能讲对题还不够。StudentSim 让研究人员在真人测试前，先模拟不同学生收到讲解后的反应，用来评估和改进教学策略。

它从公开、去标识化的学习记录中学习共性，再为每个学生单独适配，模拟其能力、常见错误和接受指导后的变化。覆盖国际象棋、英语二语写作和数学。

这里有个容易忽略的坑：大模型扮演学生时，可能语气像学生，实际却懂得太多，让老师看起来“很会教”。

据微软报告，在国际象棋实验的人类专家盲评中，导师回答准确率为：

• 用 StudentSim 反馈进行强化学习：90.5%
• 不做强化学习的基线：75.7%
• 用 GPT-5.4 模拟学生提供反馈：71.6%

对做 AI 教育的人，这提供了一个思路：把学生如何回应讲解，也纳入模型训练反馈。

https://github.com/microsoft/StudentSim
